# 一次性生成 Prompt

请用 Three.js（ES Module + importmap，本地 `vendor/` 引用，无构建、无 CDN）做一个单页网页：**可动手探索的交互式 V8 发动机**。界面文字全部中文，深色工程风格，桌面端与 390px 手机端都可用、不得横向溢出。

## 1. 物理与运动学（先写成纯函数模块 `physics.js`，所有显示都由它驱动）
- 发动机参数：90° V8，缸径 94 mm、行程 92 mm、连杆 150 mm、压缩比 11:1，DOHC 每缸 4 气门。
- 横置平面曲轴，点火顺序 1-8-4-3-6-5-7-2（奇数缸一列、偶数缸一列，每个曲柄销驱动两列各一缸）。**不要手写每缸相位**：给定点火顺序（每 90° 点火一次）和缸列角 ±45°，反解出曲柄销角度（应得到四销互成 90°，同销两缸一致）。曲轴从前端看顺时针旋转。
- 定义单缸循环角 ψ = θ − 该缸点火相位，0° = 压缩上止点：0–180 做功、180–360 排气、360–540 进气、540–720 压缩。
- 活塞位移用精确的曲柄连杆公式；连杆两端分别跟随曲柄销和活塞销。
- 气门正时：IVO 12° BTDC、IVC 48° ABDC、EVO 52° BBDC、EVC 10° ATDC（重叠 22°），升程曲线用平滑的多项式型线，进气 11.8 mm、排气 11.2 mm；进气凸轮支持 VVT 相位偏移（−20°～+40°）。
- 缸压：单区热力学（多变压缩/膨胀）+ Wiebe 燃烧放热（点火延迟、燃烧持续角随负荷/转速变化），从 IVC 积分到 EVO，之后指数衰减的自由排气、背压排气、按节气门决定的进气歧管压力。输出 0.5° 分辨率的 p、V、已燃分数、放热率、温度，以及峰值压力与位置、IMEP、扭矩、功率、爆震指数。目标量级：WOT 3000 rpm、提前角 26° 时峰值约 65–70 bar @ 约 14° ATDC。

## 2. 三维模型（全部程序化几何，禁止外部模型）
- 缸体：每列用“带缸孔与螺栓孔的截面”沿缸轴拉伸；曲轴箱用前视轮廓（U 形 + 谷底 V 形隔板）沿曲轴方向拉伸；主轴承隔板、油底壳；所有壳体必须是封闭实体。
- 曲轴：带配重的曲臂（2D 轮廓挤出）、曲柄销、主轴颈、前端链轮与减振皮带轮、后端飞轮与齿圈。
- 连杆（I 字梁 + 螺栓）、活塞（车削体，环槽 + 三道活塞环 + 活塞销）。
- 缸盖、凸轮罩、4 根凸轮轴：**凸轮型线用升程曲线按极坐标生成（凸轮 1° = 曲轴 2°）**，每个凸轮按其缸的相位安装；桶形挺柱、气门弹簧（进气蓝、排气橙，随升程压缩）、气门。
- 正时链（两条，实例化链节沿“多圆凸包切线路径”运动，2:1）、火花塞与独立点火线圈、进气稳压腔 + 8 根进气道 + 带转动蝶阀的节气门体、两侧 4-into-1 排气歧管、前端水泵/发电机/多楔带。
- 缸内气体体积：高度随活塞变化；进气蓝 → 压缩紫 → 从火花塞扩张的火焰前锋 → 做功橙红 → 排气褐；点火瞬间火花闪光；排气门打开时对应排气管短暂发红。
- 气流粒子：沿“稳压腔 → 进气道 → 进气门 → 缸内”和“缸内 → 排气门 → 歧管 → 集管”路径流动，速度与气门升程和活塞速度成正比、随慢放同步变慢。

## 3. 视图模式
- 外观：完整发动机。
- 剖切（默认）：每列壳体用过缸轴线的裁剪平面切掉谷侧一半，曲轴箱切掉上半，截面用红色斜线着色（背面着色技巧）；缸盖换成燃烧室板 + 凸轮轴承座骨架，进气歧管显示为淡幽灵材质。
- 透视：壳体为菲涅尔边缘发光的半透明材质，内部零件实体。
- 原理图：一条扫描平面横扫，把实体“擦”成蓝图线稿（填充 + 菲涅尔轮廓 + 棱线，内部零件消隐），同时摄像机做 dolly-zoom 变成近正交前视图，背景变为蓝图网格，叠加 SVG 标注：90° 夹角弧与中心线、缸径 Ø94、行程 92、凸轮轴与曲轴中心引线、图框标题栏。线稿中活塞和气体继续运动；可反向转场回 3D。
- 机位预设：全景 / 前视 / 俯视 / 侧视，OrbitControls 阻尼。

## 4. 交互与面板
- 左侧：品牌块；四冲程按钮（进气/压缩/做功/排气，点击后曲轴向前平滑转到聚焦缸的该冲程并暂停），当前冲程说明卡（中文原理 + 进/排气门开度、活塞方向、实时缸压）；聚焦气缸选择（左列 2468 / 右列 1357，键盘 1–8）；视图模式；部件标签（曲轴、连杆、活塞、凸轮轴、气门机构、正时链、火花塞/线圈、缸体、缸盖、前端附件、进气歧管、排气歧管）——选中后该部件脉冲发光、其余虚化，并显示中文讲解卡；3D 中悬停显示部件名、点击选中（拾取需排除被裁剪掉的部分）。
- 右侧：转速/扭矩/功率/IMEP 指标；“工作循环”图（p–θ 线性/对数与气门升程叠图，冲程色带、点火线、峰值标注、游标；可切到对数 p–V 环线并注明指示功）；气门正时圆图（TDC 在上、顺时针、内圈进气外圈排气、重叠扇区、点火标记、随 ψ 旋转的曲柄指针）；点火顺序条（当前做功缸点亮）+ 8 缸 × 720° 相位图（点击行切换聚焦缸）；调参滑块：转速、节气门、点火提前角、VVT，实时重算，并给出“点火过早/偏晚/合适 + 当前工况 MBT”的解释（MBT 通过扫描提前角求最大 IMEP 得到）与爆震警示。
- 底部传动条：播放/暂停（空格）、±5° 步进（方向键）、以聚焦缸 ψ 为轴、带冲程色带的可拖动刻度条、曲轴角/本缸角读数、慢放档位（1/400～实时）、声音开关。
- 声音：WebAudio 在每缸排气门打开时刻合成一次排气脉冲，奇数列偏右、偶数列偏左声像，慢放时是独立脉冲，实时时连成 V8 轰鸣。
- 3D 中每缸上方有按当前冲程着色的编号标签，点火时闪一下；顶部中央大字显示聚焦缸当前冲程。

## 5. 视觉
- 深石墨背景 + 渐隐网格地面 + 接触阴影 + 暗角；RoomEnvironment 反射 + 暖色主光 + 冷色轮廓光；UnrealBloom 只作用于燃烧与火花（阈值调高避免金属高光溢出），ACES 色调映射。
- 冲程配色固定：进气 #3fa9ff、压缩 #9a86ff、做功 #ff6a2b、排气 #dba445，所有图表与 3D 保持一致。
- 面板为半透明毛玻璃卡片，数字用等宽字体。桌面端把 3D 画面的视觉中心偏移到两侧面板之间；≤980px 时面板移到 3D 视图下方纵向排列。
