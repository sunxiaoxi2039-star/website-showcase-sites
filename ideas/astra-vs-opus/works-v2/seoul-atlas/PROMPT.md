# 一次性生成 Prompt

> 你是一名兼做 GIS 数据工程与实时图形的前端工程师。请做一个名为 **「首尔 3D 地图集」** 的网页：一块可以旋转、缩放的首尔微缩沙盘。数据要真实，观感要像桌面模型，还要带地标飞越导览和连续的昼夜光照。交付物是一个无需构建、可直接静态托管的目录。

## 一、交付与约束
- 目录结构：`index.html`、`css/style.css`、`js/{main,geo,landmarks}.js`、`data/*`、`vendor/three/*`。
- 只用相对路径，禁止 CDN。three.js r170 通过 `npm pack three@0.170.0` 拿到，拷入 `vendor/three/`（`three.module.min.js`，以及 addons 里的 OrbitControls、EffectComposer、RenderPass、ShaderPass、UnrealBloomPass、OutputPass 及其依赖），用 importmap 映射 `three` 和 `three/addons/`。
- 界面全部用中文，地名附韩文。页面顶部有一条 36px 的细顶栏：左边 `← 三方对照`，中间作品名加小标签，右边链接原作。
- 手机 390px 宽时不能横向溢出，面板改为底部抽屉。

## 二、离线数据管线（Python：pyarrow、shapely、numpy、Pillow、scipy）
1. **范围与投影**：以首尔市厅（126.978E, 37.5665N）为原点做等距投影，1 单位 = 1 km，x 向东、z 向南。沙盘范围 x∈[-21.8, 21.8]、z∈[-18.6, 18.9]。
2. **取数**：从 Overture Maps 在 S3 上的 GeoParquet（`overturemaps-us-west-2/release/<最新>/theme=*/type=*`）读取。先读每个文件的 footer，按 row group 的 bbox 统计筛选，再用 HTTP Range 只拉相交的 row group。需要的图层：buildings/building、transportation/segment（含 road_flags 里的 is_bridge / is_tunnel 区间）、base/water、base/land_use、base/land_cover、base/land、divisions/division_area（取首尔 25 个 county）。
3. **地形**：AWS Terrain Tiles 的 Terrarium z12 瓦片，重采样成 728×626 的网格（int16，单位 0.1 m）。在水域掩码内把地形压到水位（3 m）以下，陆地不低于 5.5 m；大面积的汉江压平，支流按邻域最低点下挖。
4. **建筑**：丢弃面积小于 60 ㎡ 和地下建筑，以及落在水里、地标保留区内的建筑。取最小外接旋转矩形，按面积比例缩小。高度优先用 height，其次用 num_floors×3.3+2；都缺失时按规则估算：住宅用地内、长宽比 ≥1.9、短边 9–24 m 的板楼判为公寓，高 36–70 m；小房子 5–9 m；商业大体量 18–42 m；学校和工厂压低。类型编码为：独栋、中层、公寓、玻璃塔、工业、公共、韩屋（宫阙周边）；最高位标记“首尔市界外”。每栋存 14 字节：x、z 各 uint16 量化，宽、深、高、基底高程各 uint16（单位 0.1 m），角度 uint8，类型 uint8。整体按体量降序排列。
5. **烘焙纹理（4096×3524）**：
   - `ground.jpg`：土地覆盖与用地配色，市界外降低饱和度；次级道路与铁路画成细线；全部建筑足迹画成屋顶色块并加一圈模糊接触阴影；水面填河床色。
   - `night.jpg`：道路按等级画成暖橙色光线，叠加模糊泛光，再按建筑密度加辉光；市界外调暗，水面为黑。
   - `water.png`（水域掩码，轻微模糊）；`mask.png`（R 为水、G 为绿地、B 为首尔市界内）。
6. **meta.json**：主干道（高速、快速路、主干、次干）每 40 m 加密一次的折线，每个点带标记（0 普通、1 桥、2 隧道），并按沙盘范围裁剪；25 个区的多边形（简化到 25 m），附代表点与面积；首尔市界。
7. **trees.bin**：在森林、公园、墓地、高尔夫等掩码内按概率撒 7 万棵树，每棵存 x、z、尺寸、类型。

## 三、渲染
- **地形**：索引网格，法线用中心差分计算。使用 MeshStandardMaterial，通过 `onBeforeCompile` 注入以下内容：
  - 用 `water.png` 在像素级判定水面：水色随时间变化，粗糙度 0.16，法线加上三组正弦波纹（按 `fwidth` 在远处淡出），菲涅尔项反射天空色；
  - 夜间自发光为 `pow(night.jpg, 2.3) × 夜色系数 × 随相机距离衰减的系数`；水面用 mip 偏置 5 采样灯光图，作为模糊倒影；
  - 季节色乘在绿地掩码上；下雪时铺白，下雨时整体变暗、粗糙度降低。
- **沙盘**：四边侧壁采样地形边缘，贴土层条纹纹理；底部是深色木质底座、黄铜饰条，南面有一块铭牌。
- **建筑**：12×10 个区块，每块一个 InstancedMesh（去掉底面的单位盒，底边在 y=0），实例属性 `aInfo = (宽, 夸张后高度, 深, 类型)`。每块内部按 `max(宽, 深, 高×1.6)` 降序排序；每帧算出最小可见尺寸 `1.3px × 距离 / 焦距`，二分查找后设置 `mesh.count`。片元着色器：
  - 按类型和哈希取墙色与屋顶色，屋顶约 40% 刷绿色防水漆；
  - 按层高 × 窗宽划分窗格，并用 `fwidth` 抗锯齿；窗格小于像素时过渡到平均值；
  - 墙体底部做 AO 压暗；
  - 夜间窗格按哈希和亮灯率点亮，暖色与冷白色混合；远处降到 25% 并统一为暖色；玻璃塔顶部加灯带。
- **桥梁**：只为桥段生成几何体。桥面高度取两端引桥高度插值、加一点拱度，并保证离水面有净空；侧面带夜间灯带；跨水段每 3 个点放一个桥墩。
- **车流**：14,000 个 Points 沿主干道折线靠右行驶，时间做了缩放。白天为各色车身，夜间正向为白色车头灯、反向为红色尾灯（HDR 值，参与 Bloom）。
- **天空**：天球着色器，按太阳高度角在 7 个关键帧之间插值；包含太阳盘与光晕、地平线辉光、星空（哈希加闪烁）和月亮。
- **光照**：太阳方向用首尔纬度与赤纬的公式计算；太阳高度低于 -2° 时主光切换为月光。阴影相机每帧跟随视点，半径 = 相机距离 × 0.75，并按纹素对齐。
- **后期**：HalfFloat + 4×MSAA 的 RenderTarget → UnrealBloom（夜间增强）→ 两遍可分离的移轴模糊（强度随俯仰角变化）→ 暗角与饱和度 → OutputPass（ACES）。
- **自适应画质**：帧率低于 28 时降低像素比、提高 LOD 阈值，高于 55 时回升。

## 四、地标（22 处，程序化建模，给出真实经纬度）
北汉山白云台、景福宫、昌德宫、光化门广场、清溪川、崇礼门、首尔站、N 首尔塔、兴仁之门、DDP、首尔林、乐天世界塔、乐天世界魔幻岛（石村湖岛上）、奥林匹克公园和平之门、蚕室奥林匹克主体育场、COEX、江南站、盘浦大桥月光彩虹喷泉、龙山、汝矣岛 63 大厦、首尔世界杯体育场、金浦机场。

- N 首尔塔：落在南山山顶，塔身夜间循环变色。
- 63 大厦：金色梯形挤出。
- DDP：曲线轮廓挤出并大倒角，表面有 LED 点阵。
- 城门：石台加拱门，上面是重檐门楼；兴仁之门另加半圆瓮城。
- 景福宫：宫墙、光化门、兴礼门、勤政殿（重檐加回廊）、思政殿等殿阁、庆会楼与池、香远亭、若干院落。韩式屋顶用 10 个三角面拼出四角起翘。

每个地标配一张卡片：中文名、韩文与英文名、一段说明、三项数据、坐标，以及巡游镜头参数（距离、俯角、方位）。

## 五、交互与 UI
- **OrbitControls**：拖动旋转，右键或双指平移，滚轮缩放并朝向光标，俯角上限 82°。键盘支持方向键平移、+/- 缩放、H 回全景、T 开始巡游、N 切换昼夜。
- **飞行**：目标点、方位、俯角做插值；距离在对数空间插值，中途按行程抬高形成弧线；缓动用三次 ease。
- **巡游**：依次飞过 22 站，每站停留 7.5 秒并缓慢环绕，同步更新卡片和进度条；任何手动操作都会暂停巡游。
- **标签**：地标标签为编号胶囊、引线和圆点，可点击；区名、山峰、桥梁、河流标签按距离淡入淡出；地标标签按优先级做屏幕空间碰撞避让。
- **面板**：左侧是品牌、统计和地标列表；右侧是时间（滑杆、流动按钮、清晨/正午/黄昏/夜晚预设）、季节、天气和图层开关（区界、地名、车流、树木、建筑、移轴）；左下是可点击的小地图，显示视锥投影、当前区名和坐标；底部 dock 有全景、巡游、指北。
- **区域**：鼠标悬停时显示区名、面积和海拔（通过高度场步进拾取），区界光幕随之升高；点击区域飞过去。
- **载入**：载入页显示进度条；开场从高空俯冲到全景。默认时间 17:15，季节为秋。
- **视觉风格**：深色半透明磨砂面板，金橙色主色（#f2b35e），青色辅色（#74c7cf），不使用网络字体。
