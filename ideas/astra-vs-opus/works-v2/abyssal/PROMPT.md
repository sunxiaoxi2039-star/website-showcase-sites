# 一次性生成这件作品的 Prompt

> 请做一个可静态托管的网页作品《深渊：活的深海》（ABYSSAL: The Living Deep 的致敬重制）。它是一片可以连续探索的程序化海洋：从海面随浪漂浮的镜头出发，一路潜到 1400 米，全部由同一颗种子生成，界面全部使用中文。

## 技术约束

- 只用 three.js（把 `three.module.js` 与 `three.core.js` 放进 `vendor/`，用 importmap 引入），ES Module、无构建步骤、只用相对路径、不依赖任何 CDN。
- 不使用任何贴图、模型、字体或音频文件；地形、珊瑚、动物、天空与声音全部由代码生成。
- 所有材质用自写 GLSL 的 `ShaderMaterial`，并共享同一段“水下光学”GLSL，保证任何深度下风格一致。
- 需要 WebGL2；不支持时给出中文提示。页面必须在 390px 宽的手机上不横向溢出。

## 页面框架

- 顶部一条细顶栏：左 `← 三方对照`（链接 `../../compare/index.html`），中间“深渊：活的深海” + 小标签「Opus 5.5 · 独立逆向」，右 `原作 @emollick ↗`（链接 https://x.com/emollick/status/2095673885605630429）。`?shot=1` 时隐藏顶栏，`?ui=0` 时隐藏界面。
- 画布下方叠一层 HUD（风格：深色半透明方块按钮、米白墨色、大号衬线标题、等宽小字标签、淡绿色主按钮）：
  - 左上 “ABYSSAL / 活的深海”；右上：上浮、下潜、探索（海图）、世界实验室、?。
  - 右侧深度计：大号数字 + “水面以下/以上”，下方一条可点击的深度刻度 0 水面 / 200 暮光带 / 600 下暮光带 / 1,000 午夜带 / ≈1,400 热液区，并有随深度移动的标记。
  - 左下标题区：随所处区域淡入切换的大标题与副标题（呼吸之海、珊瑚大教堂、沉没的森林、深入蔚蓝、暮光带、漫长的暮光、午夜之水、午夜花园、玄武岩平原），一行“附近 · 物种 · 物种…”；在海面时显示“潜入珊瑚礁”按钮。
  - 底部四个生境标签（珊瑚礁 / 海藻林 / 开阔大洋 / 深渊，快捷键 1–4），当前区域有下划线。
  - 右下工具栏：漂流、游动、暂停、潜水灯、观察、图鉴、截图（不含界面的 PNG），下方一行提示。
  - 旅程进行中在顶部显示“正在前往 · X”进度条与“停在这里”。

## 世界生成（同一片海）

- 种子（数字或文字，文字哈希成稳定整数；默认 713）→ 在 4.8 km 见方范围内烘焙 768² 的 RG32F 高度图（高度 + 细节幅度）与 RGBA 生境图，再加一张 256² 可平铺细节噪声。GPU 顶点着色器用 `texelFetch` 手写双线性采样；CPU 用完全相同的公式采样，用于碰撞、动物贴地与路线规划。
- 布局：北侧陆架（-15 到 -30 米）；西侧是沿东北向延伸的珊瑚脊与沙质水道，东侧是岩质海藻林与林间空地；陆架边缘突然坠入陆坡，一条蜿蜒峡谷从陆架切到深渊；南侧是约 -1400 米起伏的深渊平原，散布着热液带。可航行半径 2.2 km。
- 四个站点（reef / kelp / blue / deep）与 11 个目的地（reef-ridges、reef-channels、reef-gardens、kelp-avenues、kelp-clearings、kelp-outer、shelf-edge、canyon-wall、vent-belt、basalt-plain、far-vents）都只是这片海里的坐标。
- 镜头周围的地形用一张以镜头为中心、近密远疏的网格（近处约 0.75 米一格）实时采样高度图，并在片元里加沙纹、岩面凹凸、藻皮与生境着色。

## 光与水

- 三通道的下行衰减 Kd、视线衰减 Kv、散射系数 b；沿视线的内散射用解析积分（起点深度、方向、长度），水下穹顶就是 L→∞ 的积分。清澈度、上升流（更绿）、离岸（更清）、沉积物都只改这三组系数。
- 焦散：两层随时间漂移的“绝对值噪声网”，沿折射后的太阳方向投影，随深度变弱变糊。
- 沿折射太阳方向的 2048² 正交阴影图，只覆盖镜头前方约 64 米。
- 自动曝光；潜水相机式部分白平衡（浅处按阳光路径、深处按潜水灯往返路径补偿红光）。
- 两盏潜水灯（自动随深度亮起，可手动覆盖）。生物发光的强度按 1/曝光 缩放。
- 后期：半分辨率体积光（阳光光柱 + 灯光光束）、两级泛光、ACES、暗角与细颗粒。镜头靠近水线时把场景渲两遍，逐像素用 GLSL 里的浪高判断水上/水下，做出随浪移动的分屏与暗色水膜线。

## 海面与天空

- 12 个 Gerstner 波（由风速估算峰值波长与波高，加上涌浪），CPU 与 GPU 同参数；漂浮镜头用 CPU 迭代反解真实浪高并随浪倾斜。海面从空中看：天空反射 + 太阳高光 + 浪峰次表面散射 + 雅可比泡沫；从水下看：斯涅尔窗与全反射。事件波：海底震颤的环形波列、畸形浪波包。
- 天空：解析大气渐变 + 在云层薄壳里 14 步步进的积云（阈值随高度升高形成圆顶，朝太阳采样做自阴影与银边）+ 夜空的星、月与银河带；雨线与分叉闪电。夜里上升流喂养的表层藻华在浪峰被扰动时发出青绿色光。

## 景物（程序化 + 实例化）

- 分层石灰岩台地（顶上长珊瑚）、巨石、陆坡石柱、玄武岩、鹿角珊瑚、脑珊瑚、桌状珊瑚、海扇、海鞭、管状与桶状海绵、巨藻（高度随水深与“海藻高度”旋钮，顶点着色器弯曲并随波浪涌动）、海草丛、冷水珊瑚、矿物烟囱（顶上升起羽流粒子）与管虫丛。
- 以 32 米地块、世界坐标为种子播种；只展开镜头附近的地块，逐帧做视锥与距离剔除；回到同一地点群落不变。

## 动物（约 30 个物种群体）

- 珊瑚礁：蝴蝶鱼、鹦嘴鱼、雀鲷、礁鲨、蝠鲼、章鱼、螃蟹、海星、海胆；海藻林：海豹、银色鱼群、海龟；蔚蓝：座头鲸、海豚、金枪鱼、翻车鱼、鱿鱼；200–1000 米：灯笼鱼、斧头鱼、中层水虾、吸血鬼乌贼、龙鱼；1000 米以下：鮟鱇、宽咽鱼、烟灰蛸；深海底：大王具足虫、蛇尾、海参、海鳃、热泉虾；漂流者：水母、管水母。
- 每个物种一套程序化解剖（放样躯干、尾鳍/背鳍/臀鳍/胸鳍、腕足、眼睛、发光器官），顶点属性记录脊柱坐标、拍动权重、腕编号、发光与收缩，通用顶点着色器做身体波动、鳍的拍动、腕的卷曲、步足交替与伞体收缩。
- 30Hz 固定步长 + 插值渲染：鱼群分离/对齐/聚合，前瞻避地形与大石，被掠食者或正在游动的潜水员惊散后重聚；礁鱼游到岩面低头啄食；掠食者偶尔追向附近的猎物群；海豚、海豹、海龟、座头鲸周期性上浮换气；底栖动物走一段停一段、螃蟹横行；鱿鱼喷水后退；水母脉动漂流；热泉虾围着烟囱打转；转弯时侧倾。暂停时位置与附肢一起冻结；漂流模式下镜头不惊扰动物。
- 群落按镜头周围的生境适宜度加载与回收，初次生成多放在镜头前方；深处群落半径收拢到潜水灯范围。实验室里显示的是当前加载的数量。

## 交互

- 漂流 / 游动（WASD 沿视线游动、拖动环顾、Q/E 下沉上升、Shift 加速、滚轮缩放）；上浮、沿峡谷下潜（已在深水区则直接下沉）、深度站点、1–4 生境旅程、海图目的地或海图任意一点；旅程沿地形平滑并可“停在这里”。
- 世界实验室四个页签：世界（种子、新种子、地形起伏、生物覆盖、海藻高度、生境尺度、重置配方、复制世界链接）、生命（动物丰度、掠食者、底栖生物、水母与漂流者、鱼群规模、当前加载数量）、水体（清澈度、洋流、生物发光、深层上升流、潜水灯 自动/开/关、海洋声音与音量）、天气（白天/黄昏/风暴/夜晚、太阳高度、云量、风速、涌浪、风暴强度，展开更多：风向、涌浪周期、浪尖陡度、降雨、雾霾、云密度；事件：海底震颤、畸形浪、闪电）；底部“视图与控制”：在水线漂浮、画质、帧率、操作说明。地形类旋钮松开时重建，天气与水体旋钮拖动时实时生效。
- 观察（O）：选中视野里看得清的动物，屏幕上用四角括号跟随，卡片显示名称、描述、距离与深度，可“跟随”（镜头缓缓移到舒适距离）、“下一个”；点画面上的动物也能选中。
- 野外图鉴（J）：动物需要在画面里停留约 1 秒、距离足够近、没被地形挡住、并且被阳光/潜水灯/自身发光照亮才记录；记录首次深度与种子，存在 localStorage（读写包 try/catch）。
- 海洋声音（M，默认关闭）：WebAudio 实时合成浪涌、水下低鸣、礁区噼啪、远处的鲸歌、热泉嘶声与震颤低频。
- 快捷键：G 实验室、R 新种子、C 海图、L 潜水灯、P 暂停、H 隐藏界面、F 漂流/游动、Esc 关闭。
- URL 参数：`site`、`place`、`seed`、`light`（day/dusk/storm/night）、`surface`（1 / waterline）、`depth`（200/600/1000/vent）、`relief`、`cover`、`height`、`habitatScale`、`life`、`predators`、`benthos`、`jellies`、`shoal`、`clarity`、`current`、`glow`、`upwelling`、`lamp`、`preset`、`adaptive=0`。
- 自适应内部分辨率保帧率；手机默认低画质（关闭阴影）。
