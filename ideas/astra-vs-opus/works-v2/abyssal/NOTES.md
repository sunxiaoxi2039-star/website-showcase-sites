# 深渊：活的深海 —— 独立逆向笔记

## 我对原作的理解（它的核心卖点是什么）

ABYSSAL: The Living Deep 最打动人的不是某一个特效，而是**“连续”**：
从海面上随浪漂浮的一个镜头开始，一口气潜下去——阳光珊瑚礁、海藻林、陆架边缘的蔚蓝、峡谷里的暮光带，一直到 1400 米的热液花园——中间没有加载、没有切场景，全都是同一颗种子长出来的同一片海。站点按钮只是“旅程”，不是“传送门”。

第二个卖点是**“活”**：动物不是贴在场景里的装饰，而是有形态、有行为的群落——鱼群彼此保持间距、被掠食者或潜水员惊散再合拢，礁鱼低头啄食，螃蟹横着走一段停一段，海豚与海豹会周期性上浮换气，鱿鱼喷水后退；越往下，光越少，动物开始自己发光。

第三个卖点是**“可以玩的配方”**：种子、地形、生物覆盖、种群、水体光学、天气全都是实时旋钮，还能复制成可复现的链接；再加上观察模式和野外图鉴，把“看风景”变成了“做一次潜水考察”。

## 实现思路与关键技术决策（为什么这么选）

- **Three.js（r186，本地 vendor）+ 全部自写 GLSL 的 ShaderMaterial**。没有用标准材质，因为每一种材质（地形、景物、动物、粒子、海面）都必须走同一套“水下光学”函数，才能在任何深度下保持一致。无构建步骤，ES Module + importmap。
- **地形 = 烘焙高度图 + 可平铺细节噪声，GPU 用 `texelFetch` 手写插值**。CPU 端用完全相同的插值公式采样同一份 Float32 数据，所以碰撞、动物贴地、路线规划与画面严格一致（这是 README 测试里强调的点）。渲染网格是以镜头为中心、近密远疏的一张 257×257 网格（近处 0.75 米，远处约 9 米）。
- **一套解析的水体模型**：下行辐照 `E(d)=E0·e^{-Kd·d}`（三通道），视线内散射用解析积分 `b·phase·E0·e^{-Kd·d0}·(e^{aL}-1)/a`，所以“往上看变亮、往下看变暗、远处融进水色”都是同一个公式的结果；天空穹顶在水下就是 L→∞ 的这条积分。清澈度、上升流、离岸距离、沉积物都只改 Kd/Kv/b 三组系数。
- **像潜水相机那样的部分白平衡**：浅处按阳光下行路径补偿红光，深处按潜水灯约 12 米往返路径补偿。这是刻意的艺术选择——让礁石有颜色、让深海在灯下是 ROV 画面那种中性色，而不是一片青绿。
- **自动曝光 + “按曝光归一化的生物光”**：深处曝光会拉到几十倍，生物发光的自发光强度按 1/曝光 缩放，这样灯笼鱼的腹部发光在 600 米和 1000 米看起来同样亮，在浅海白天则几乎看不见。
- **后期管线**：HDR 场景 → 半分辨率体积光（沿视线步进，同时积分阳光光柱与两盏潜水灯的光束）→ 两级泛光 → ACES → 暗角/颗粒。水线附近把场景渲两遍（水上/水下），逐像素用 GLSL 里的 Gerstner 浪高判断近裁剪面在不在水下，做出随浪移动的分屏。
- **海面**：12 个 Gerstner 波（风浪 + 涌浪，按风速估算峰值波长与有效波高），JS 与 GLSL 同一组参数；镜头漂浮时用 CPU 迭代反解真实浪高并随浪面倾斜。事件波（海底震颤的环形波列、畸形浪波包）同时写进两边。从水下看是斯涅尔窗 + 全反射。
- **天空**：穹顶里在 1300–2200 米的云层中做 14 步的“2.5D 体积云”（二维覆盖场 + 随高度抬高的阈值 → 积云圆顶），朝太阳方向采样一次做自阴影；反射里用便宜的二维版本。夜晚有星、月、银河带。
- **景物**：岩石（分层台地、巨石、石柱、玄武岩）、鹿角珊瑚、脑珊瑚、桌状珊瑚、海扇、海鞭、管状/桶状海绵、巨藻、海草、矿物烟囱、管虫全部是程序化网格，每类几个变体，用 InstancedMesh 画。按 32 米地块、以世界坐标为种子播种，镜头附近展开，逐帧做视锥与距离剔除。珊瑚会“长”在台地顶上。海藻用顶点着色器按高度弯曲，叠加洋流与波浪涌动。
- **水下阳光阴影**：沿折射后的太阳方向做一张 2048² 的正交深度图，只覆盖镜头前方 64 米，按纹素对齐防闪烁，越深越软越淡。
- **动物**：32 个物种群体，每个物种一套程序化解剖（放样躯干 + 鳍片 + 腕足 + 发光器官 + 眼睛），顶点属性里存“脊柱坐标 / 拍动权重 / 腕编号 / 发光 / 收缩”，一个通用顶点着色器按物种参数做身体波动、鳍的拍动（带展向相位滞后）、腕的卷曲、步足交替和伞体收缩。行为在 30Hz 固定步长里跑：鱼群三规则、群体目标漫游、前瞻避地形、避大石、惊散与重聚、礁鱼觅食低头、掠食者偶尔追向附近猎物群、呼吸空气的动物周期性上浮、底栖动物“走一段停一段”（螃蟹横行）、鱿鱼喷射后退、水母脉动漂流、热泉虾围着烟囱打转。
- **群落管理**：每个物种周期性地在镜头周围采样“适宜度”，决定目标数量；在视野外补生、远离回收；初次到达时把多数群体放在镜头前方。深处群落半径随深度收拢到潜水灯可及范围。
- **界面**全中文，信息架构照原作：标题会随区域淡入切换（呼吸之海 / 珊瑚大教堂 / 沉没的森林 / 深入蔚蓝 / 暮光带 / 漫长的暮光 / 午夜之水 / 午夜花园 / 玄武岩平原），深度刻度可点击作为深度站点，世界实验室四个页签，海图，观察，图鉴，帮助，触屏按钮。

## 和「常规做法」相比，我做了哪些不一样的尝试

1. **不用雾，用“解析水体”**。常规做法是 `scene.fog` 或者按距离混一个水色；这里每个像素都按视线方向、起点深度和长度解析积分内散射，所以同一个函数自然产生了：往上看的亮、往下看的暗、朝太阳方向的前向散射光晕、深处的漆黑。
2. **一张高度图同时服务 GPU 和 CPU**，靠手写插值保证逐位一致，而不是“渲染一套、碰撞另一套近似”。
3. **“按曝光归一化的生物光”与“按潜水灯路径的白平衡”**——为了让深海在极端曝光下仍然好看，这两个小决定比任何后期都重要。
4. **海图直接从世界数据渲染**：晕渲 + 生境着色 + 等深线（50/200/600/1000 米）+ 峡谷线 + 实时位置与朝向 + 旅程路线；除了 11 个目的地，还可以点海图上任意一点出发（原作没有提到这一点）。
5. **图鉴识别做了真正的可见性判断**：画框内、距离、地形遮挡（沿视线采样高度图）、光照（阳光曝光阈值 / 潜水灯锥 / 自身发光），而不是“进入半径就算看见”。
6. 多加了原作列表之外的**雀鲷群**（悬停在珊瑚丛上方的小鱼），让礁区“满”起来。

## 踩过的坑与修正过程

- **第一张水下截图只有一片青色**：看起来像地形没画出来，实际是散射系数太大、红光衰减太狠，地面被“淹”在水色里。把 b/Kv 比例降到真实大洋的量级、加上部分白平衡后，沙地和焦散才出来。
- **InstancedMesh + 自写管道几何全部“里外翻面”**：平行传输标架下 `T×B = -N`，四边形绕序反了，珊瑚只剩背面、桌状珊瑚变成地上的黑斑。修正绕序后正常。
- **台地像飘在空中的蘑菇**：底部内凹 + 埋入深度不对，算清几何的 y 范围后改成少量内收、以“下缘略埋”定位。
- **海平线上一排小黑点**：极坐标海面网格的最外圈是多边形，弦中点露出了穹顶的深水色。改成海面远处与穹顶在水平线附近使用同一个 `seaHorizon()` 颜色，并加密分段。
- **云像被压扁的层云**：纯二维云层在低仰角被透视压成条纹。换成薄层内 14 步步进、阈值随高度升高，云才有了侧面和圆顶；时间抖动带来的颗粒改成静态的交错梯度噪声。
- **深海整屏被潜水灯光束糊成一片青色**：光束内散射借用了阳光光柱的放大系数，而且用的是偏青的散射系数。拆成单独的、中性的灯光散射项，并对体积光做 4 点模糊压住抖动纹理；曝光公式里提高灯的权重，灯下物体不再过曝。
- **“蔚蓝”站点一只动物都看不见**：生境适宜度采样把中层鱼的高度钳在“离底 20–200 米”里，而这里海底在 470 米以下，全被判成不适宜。改成在深度窗口内采样两次取较大值，并放宽大洋物种的离底上限。
- **动物都在身后或太远**：初次生成改为多数群体放在镜头前方，小型礁鱼用更小的生成半径并偏向近处；深处群落半径收拢到灯光范围。
- **无头 swiftshader 下帧率只有 1–2 fps**，所有截图都要等十几秒；为此写了批量截图脚本，并把 CPU 端的动物模拟单独放到 Node 里测（约 1.5–3 ms/步）。

## 自评：和原作相比，哪里可能追平或超越，哪里还差

**可能追平或超越的地方**
- 完整实现了原作 README 描述的体验骨架：海面开场 → 连续旅程 → 四个生境 + 11 个目的地的同一片海、沿峡谷下潜、深度站点、停在这里、漂流/游动、世界实验室四页签、复制链接、观察与跟随、图鉴、合成声音、震颤/畸形浪/闪电、水线分屏、夜间藻华发光。
- 珊瑚礁、海藻林、暮光带三处画面与原作文档截图的气质相当接近，礁区的鱼种与珊瑚形态更丰富一些。
- 图鉴的可见性判断、海图可点任意一点、按曝光归一化的生物光，是我认为比较扎实的加分项。
- 全部代码约 6,900 行、无贴图/模型/音频资源，首屏只需 three.js 一个依赖。

**还差的地方**
- 海面是 12 个 Gerstner 波而不是原作的多级 FFT；飓风、龙卷水柱、漩涡、海啸没有做，只做了震颤、畸形浪、闪电与雨。
- 云是“2.5D 体积”，近看边缘仍有抖动纹理；没有 TAA，没有景深与运动模糊。
- 动物模型是低多边形的程序化形态，近看不如原作精细；鲸鱼在“蔚蓝”站点不一定正好出现在画面里。
- 深海地面的颜色和沙纹仍偏平，细节纹理远不如原作的石灰岩。
- 我只能在软件渲染器里验证，真实 GPU 上的帧率是按经验估计的（带自适应分辨率兜底）。

## 如果重来一次会怎么做

1. 先搭“截图 + 数值探针”的验证脚手架，再写渲染：这次前期很多时间耗在“为什么画面是一片青色”上。
2. 海面直接上 GPU FFT（两到三级级联），并与水下共享同一张位移纹理，水线和焦散会更真实。
3. 加 TAA，把云、体积光、阴影的抖动都交给时间累积，而不是靠模糊。
4. 给动物做一次“二级细节”：近处用更高细分的网格与法线扰动的鳞片/皮肤，远处保留现在的低模。
5. 把群落生成做成“以世界坐标为种子的地块”，这样动物也能像珊瑚一样“回到原地仍在”。
