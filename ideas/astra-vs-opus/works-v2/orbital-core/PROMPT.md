# 一次性生成 Prompt：轨道能量核心（Orbital Core）

> 用途：让一个代码模型在一次回复里生成本作品的完整静态站点。

---

请用 **Three.js（r181，ES Module + importmap，本地 `vendor/` 目录，不用 CDN、不用构建工具）** 做一个单页 3D 产品展示网页，主角是一件「双环能量核心」。目标是：看起来像一件在 Blender 里精细建模、用 Cycles/Eevee 渲过的硬表面产品，而不是一个球加两个甜甜圈。界面文字全部用中文。

## 文件结构
```
index.html        入口（importmap: "three" → ./vendor/three/three.module.min.js，"three/addons/" → ./vendor/three/addons/）
css/style.css
js/model.js       程序化建模：导出 buildOrbitalCore() → { root, parts, uniforms, materials }
js/main.js        渲染器、环境光照、后期、相机、交互、模式状态机、UI 联动
js/audio.js       WebAudio 合成的核心嗡鸣
vendor/           three.module.min.js + three.core.min.js + OrbitControls / EffectComposer / RenderPass / UnrealBloomPass / OutputPass / ShaderPass 及其依赖；字体 woff2
```

## 模型（全部程序化，不加载外部模型）
写一个 `sweepProfile(profile, {phi0, phi1, steps, closed, caps})`：把二维截面 `[(r, y)…]` 绕 Y 轴扫掠（等同 Blender 的 Spin/Screw 修改器）。**每条截面边单独生成一条带状面、拥有自己的法线**，这样倒角面会成为清晰的高光线；可选在 phi0/phi1 处用 `ShapeUtils.triangulateShape` 封端；按顶点法线自动修正三角形绕序。UV 的 u 沿圆周方向，便于做「车削金属」拉丝。

1. **等离子核心**：半径 0.5 的球，ShaderMaterial，3D simplex 噪声 + 域扭曲 fbm 生成对流胞，再叠 `pow(1-|noise|, 9)` 的亮丝；深蓝→钴蓝→白热三段色，输出 HDR（>1）供辉光使用；边缘加一点日冕亮边。外面套两层 BackSide 加法混合的菲涅耳光晕球（0.86、1.35）。
2. **测地约束笼**：`IcosahedronGeometry(0.66, 1)` 去重顶点、提取 120 条边 → InstancedMesh 细圆柱支杆 + 42 个八面体钛合金节点 + 12 个五度顶点上的小 LED。整个笼缓慢自转。
3. **陀螺架双环（重点）**：外环 R=1.42 竖直、随万向架绕 Y 转（方位 α）；内环 R=1.16 由两根阶梯钛销挂在外环 ±X 处，绕 X 轴翻转（俯仰 β）——是真正能转的万向节，而不是两个相交的圆环。每道环：
   - 截面是带 0.014 倒角的矩形，外表面开一条凹槽；
   - 环体切成 12/10 段，段间留 0.03 rad 缝，每段两端封口；
   - 凹槽里有一条连续的发光导轨，环体中心有一条「脊」发光条，**只从切缝里透出来**，所以每条缝都是一道蓝光；
   - 在 0°/90°/180°/270° 放加厚的钛合金卡箍，上面各有三颗 LED（两冷一暖琥珀色点缀）。
   - 万向架整体再倾斜 ~0.2 rad，并带一点缓慢进动。
4. **悬浮基座**：一条带台阶、倒角、环形凹槽的截面扫掠成整体；凹槽内发光环；中心是菲涅耳纹发射透镜（同心阶梯 shader）；台面上叠一张 Canvas 画的刻度盘（2° 细刻度、10°/30° 长刻度、环形微缩字 `ORBITAL CORE · SPECIMEN 01 …`、4 个三角索引），加法混合，随 α 慢转；侧面 72 片散热鳍（InstancedMesh）；台阶立面 24 条状态灯缝；从透镜到核心有一束带流动条纹的加法光柱。
5. **地台**：大圆形暗色地面 + 放射渐变的「烘焙 AO」接触阴影贴片 + 一张加法混合的地面特效 shader（基座下的光池、每 1.45 单位一圈的虚线测量环、外圈细刻度、脉冲模式下的扩散冲击波）。

## 材质与光照（「Blender 质感」的关键）
- 程序化拉丝贴图：Canvas 上画几千条沿 u 方向的随机灰线 → 作为 roughnessMap；环体与基座用 `MeshPhysicalMaterial`，`metalness 1`，环体带 clearcoat，基座开 `anisotropy`，得到车削金属那种放射状高光。
- 自己搭一个迷你「HDRI 棚」：在一个场景里放暗色渐变天球 + 顶部大柔光箱 + 左侧冷蓝灯条 + 右侧白灯条 + 背后地平线蓝光 + 一小块暖色反光板，用 `PMREMGenerator.fromScene` 烘成 `scene.environment`。
- 核心内放一盏投射阴影的点光源（强度随能量变化），让环、笼的影子落到基座上；再加一盏冷白主光和一盏蓝色轮廓光。
- 背景是一个与 FogExp2 同色的天穹 shader，地面在远处无缝溶进去，不能出现地平线硬边。
- 后期：`EffectComposer`（HalfFloat、MSAA 4x 的 render target）→ `UnrealBloomPass`（强度 ~0.45、半径 0.4、阈值 0.95，只让 HDR 发光体溢光）→ `OutputPass`（ACES）→ 自定义 ShaderPass：边缘轻微色散 + 暗角 + 胶片颗粒抖动（顺便消除暗部色带）。

## 交互与状态机
- OrbitControls：阻尼、禁平移、限制俯仰不钻到地下；距离按视口宽高比自动计算（竖屏更远），用 `camera.setViewOffset` 在桌面把模型略微推向右侧给标题让位，手机上略微下移。
- 开场：相机从远处低角度 3.4 秒缓入，核心在 0.35–2 秒间「点火」（按真实时间计，慢设备也能播完）；用户一拖动就立刻交出控制权。双击或按 R 平滑复位。
- 四个模式（按钮 + 键盘 1–4）：
  - **轨道**：α、β 慢转，相机自动环绕，核心轻微呼吸；
  - **脉冲**：转速加快，能量按「咚-哒」双峰心跳包络跳动（1.25 s 周期），每一拍地面扩散一圈冲击波、声音里出一记低频 thump；
  - **静止**：所有转速阻尼归零，核心待机微光，状态灯变琥珀色；
  - **拆解**：万向架回正，外环抬到上方、内环落到下方并都转平，笼子放大，核心上浮，相机目标上移；出现 5 个带引线的 HTML 标注（等离子核心 / 测地约束笼 / 外环·方位环 / 内环·俯仰环 / 悬浮基座，附尺寸规格），锚点每帧投影，环类标注自动取屏幕上最外侧的点，标注在手机上夹紧在视口内。
- 所有速度、能量、拆解进度都用指数阻尼平滑，切换模式没有跳变。
- 自适应分辨率：帧率低于 30 时逐步把 pixelRatio 降到 1。

## UI（叠在画布上）
- 最顶部一条 34px 细顶栏：左「← 三方对照」、中「轨道能量核心」+ 小胶囊标签、右「原作 @作者 ↗」。
- 左上品牌「ORBITAL / OBJECTS」+ 小轨道图标；右上「样本 01 / DUAL-RING CONTAINMENT」。
- 左侧大标题（衬线体，第二行斜体渐变字）：「两道轨道 / 一颗恒星。」+ 一段短说明。
- 右侧实时参数表：状态、核心频率（THz）、外环方位 α、内环俯仰 β、场强输出 %，底下是一条画出能量历史的小示波器。
- 左下四个模式按钮（带小图形符号和键位提示），页脚操作提示 + 声音开关（WebAudio：两支微失谐锯齿波过共振低通 + 次低频正弦 + 高频微光颤音，滤波截止随能量和转速变化）。
- 背景加 76px 细网格（遮罩渐隐）和 SVG 噪点颗粒。
- ≤740px：标题移到上方、隐藏说明段，参数表变成三列横条，四个按钮平分一行；390px 宽不能横向溢出。
- 字体：Instrument Serif（标题）+ IBM Plex Mono（数据），woff2 放 vendor，中文回退到系统宋体/黑体。

## 质量要求
- 控制台零报错；WebGL 创建失败时显示中文提示。
- 所有发光色用 HDR 值，靠辉光而不是把漫反射调亮来「发光」。
- 暗部要深（钴蓝-近黑），不要整体泛白发灰。
