GPT-6 Astra×Opus 5.5 同题对打 · 20 道Same prompt, head to head · 20 rounds

从公开仓库里挑出 20 件 Astra 作品（带原始 prompt 的），把 prompt 一字不改交给 Opus 5.5 的独立子代理，让它在看不到原作的情况下重新做一遍。之后两边用同一套脚本截图，再由看不到出处的评审代理盲评打分。

We picked 20 Astra works from public repositories — ones that came with their original prompt — and handed each prompt, word for word, to an independent Opus 5.5 subagent, which rebuilt the piece without ever seeing the original. Both sides were then screenshotted with the same script and scored by a judge agent that couldn't tell which was which.

01① 同一道题① Same prompt原 prompt 原封不动；原作者追加过反馈的，也原样补给 5.5。格式约束跟原作一致（单文件就单文件）。The original prompt, untouched; where the author sent follow-up feedback, 5.5 got that too, verbatim. Format constraints match the original (single file means single file).
02② 盲做② Built blind每道题一个全新子代理、记忆隔离，明令禁止查看 / 搜索原作的代码、截图、仓库与在线页。A fresh subagent per prompt with isolated memory, explicitly forbidden to view or search for the original's code, screenshots, repo or live page.
03③ 统一截图③ Identical screenshots两边都在同一台机器、同一个无头 Chromium（软件 WebGL）、1400×875、加载后等 4 秒截图。Both sides captured on the same machine, in the same headless Chromium (software WebGL), at 1400×875, 4 seconds after load.
04④ 盲评④ Blind judging评审代理只看到「作品 A / 作品 B」，A/B 随机分配，按五项各 10 分打分并写理由；合计高者胜，相差 ≤ 1 分记平局。盲评副本里「Created with …」之类的署名字样已抹掉。The judge sees only "Work A / Work B", randomly assigned, and scores five criteria out of 10 with written reasons; the higher total wins, and a gap of ≤ 1 point is a tie. Credits like "Created with …" were scrubbed from the judging copies.

i18n本页可切换中英文；但每件作品的界面语言跟随原题（这是比赛规则的一部分：英文题做英文界面，中文题做中文界面），所以作品本身不做双语。This page switches between Chinese and English, but each work's interface language follows its original prompt — part of the rules (English prompts get English UIs, Chinese prompts Chinese ones) — so the works themselves are not bilingual.

先说清楚这场比赛哪里不公平：First, where this match is unfair:
  • 投入不对等，偏向 5.5。17 件 MiaAI 作品是一次性批量生成的 100 件之一，单件只有 2–5 KB；5.5 每道题独占一个代理，还能自己开浏览器截图、反复修改。等于拿「一口气写 100 篇的随堂作文」对「单篇精修」。
  • Unequal effort, in 5.5's favor. The 17 MiaAI works are from a batch of 100 generated in one go, just 2–5 KB each; 5.5 got a dedicated agent per prompt that could open a browser, take screenshots and revise again and again. It's an in-class essay dashed off as one of a hundred versus a single polished piece.
  • 评委也是 Claude。我们没有第三方模型可用，盲评代理同样是 Opus 5.5。A/B 虽然匿名，但它可能认得出自家风格——这一偏差没法完全消除，请把分数当参考。
  • The judge is Claude too. We had no third-party model available, so the judging agent is also Opus 5.5. A/B is anonymous, but it may recognize its own house style — a bias we can't fully remove, so treat the scores as a reference.
  • 雷霆战机的原作是多轮迭代（原作者说明用了协作代理、审阅与造型返工），不是 one-shot；5.5 这边拿到了原题 + 那条返工反馈，但只做一轮任务。
  • Thunderfall's original went through several rounds (the author mentions collaborating agents, review and a model rework) — it isn't one-shot. 5.5 got the original prompt plus that rework feedback, but did it as a single task.
  • 截图用的是软件渲染，重型 WebGL 在真机上会更流畅；两边吃的是同一个亏。
  • Screenshots use software rendering, so heavy WebGL runs more smoothly on real devices; both sides take the same hit.

批量组：差距主要是「投入」差出来的Batch group: the gap is mostly about effort

17 道 MiaAI 题的平均总分 。但 Astra 那边每件只有 2–5 KB，是一口气生成 100 件时的产物；5.5 这边每件独占一个代理，自己开浏览器截图、改了 4–10 轮，文件 40–340 KB（大头常是内联字体）。评委挑出的 Astra 问题——粒子是静止网格、控件掉到首屏外、题目点名的效果只做了一半——正是「随堂作文」会有的问题。这组比分说明的是「同一道题，投入多一个数量级时能做到什么」，不能直接读成模型差距。

The 17 MiaAI prompts average . But each Astra piece is only 2–5 KB, produced while generating 100 at once; each 5.5 piece had its own agent, which took its own screenshots and revised 4–10 times, ending up at 40–340 KB (often mostly inlined fonts). The Astra problems the judge flagged — particles on a static grid, controls pushed below the fold, only half of the effect the prompt named — are exactly what you'd expect from a rushed in-class essay. This group shows what the same prompt can yield with an order of magnitude more effort; it shouldn't be read as a straight gap between models.

重量级组：真正值得看的三道Heavyweight group: the three worth watching

Astra 原作是单独打磨的游戏（苔翼 One Shot + Xhigh 用时 21 分钟；瓜体实验室 One Shot、5 MB；雷霆战机多轮迭代 + 协作审阅）。平均总分 ，5.5 仍然三题全胜，但差距缩到 3–5.5 分。

Here the Astra originals are individually polished games (Mosswing: one shot + Xhigh, 21 minutes; Melon Lab: one shot, 5 MB; Thunderfall: multi-round iteration + collaborative review). Average totals: . 5.5 still wins all three, but the margins shrink to 3–5.5 points.

  • Astra 更强的地方：界面与系统的成品感——苔翼有暂停 / 静音 / WebGL 失败提示，瓜体实验室有精绘水果贴图和三档流动性，雷霆战机有关间强化、擦弹充能、难度选择。
  • 5.5 更强的地方：对题目「那个味儿」的把握——真透视 3D 的沼泽、真的面积守恒会流动的「半流体」、带地面单位和专属 BOSS 的「雷电」。
  • 5.5 也有实打实的 bug：苔翼的粒子 alpha 恒为 0 全部不可见、瓜冻实验室没有暂停、雷霆战机难度偏高没有难度选项。
  • Where Astra is stronger: product-grade polish in interface and systems — Mosswing has pause / mute / a WebGL-failure message, Melon Lab has hand-painted fruit textures and three fluidity levels, Thunderfall has between-stage upgrades, graze charging and difficulty selection.
  • Where 5.5 is stronger: capturing the prompt's "feel" — a swamp in true perspective 3D, a "semi-fluid" that really conserves area and flows, and a "Raiden" with ground units and dedicated bosses.
  • 5.5 has real bugs too: Mosswing's particle alpha is stuck at 0 so every particle is invisible, Melon Jelly Lab has no pause, and Thunderfall runs hard with no difficulty option.

几条心得Takeaways

  • 自测闭环是 5.5 最大的优势。20 件交付物在两种视口下全部零报错、零横向溢出、零外部网络请求——因为每个代理都被要求自己截图、亲眼看、再改。批量组里 Astra 输掉的分，很大一部分是「没检查」的分。
  • 原作投入越多，差距越小。批量组平均分差 分，重量级组只有 分。差距最小的是只有一句话的「半流体西瓜」（首评 3 分，换标签复评只差 1.5 分，基本算打平）——题目越开放，两边越得靠自己发明玩法，比的更接近「点子」本身。
  • 代价不低。20 件一共约 token、 代理分钟（多个代理并行），单件从 7 分钟到 57 分钟不等；雷霆战机一件就用了 30 万 token。
  • 评分只能当参考。评委同样是 Claude，下面的换标签复核只排除了「偏好 A 位 / B 位」这一种偏差，排除不了「偏好自家风格」。最可靠的还是你自己点开两边玩一下——每道题都有原作链接和 5.5 的可运行版本。
  • Closed-loop self-testing is 5.5's biggest advantage. All 20 deliverables have zero errors, zero horizontal overflow and zero external network requests in both viewports — because every agent had to take its own screenshots, look at them and revise. Much of what Astra lost in the batch group was points for "not checking".
  • The more effort in the original, the smaller the gap. The average gap is points in the batch group but only in the heavyweight group. The smallest gap is the one-line "semi-fluid watermelon" prompt (3 points in the first judging, just 1.5 on the label-swapped rejudge — essentially a draw): the more open the prompt, the more both sides must invent their own gameplay, and the closer the contest comes to comparing ideas.
  • It isn't cheap. The 20 pieces took about tokens and agent-minutes in total (several agents in parallel), from 7 to 57 minutes each; Thunderfall alone used 300k tokens.
  • Treat the scores as a reference only. The judge is also Claude; the label-swap recheck below rules out just one bias (favoring slot A or B), not a preference for its own style. The most reliable test is still to open both and play — every prompt links to the original and to 5.5's runnable version.
