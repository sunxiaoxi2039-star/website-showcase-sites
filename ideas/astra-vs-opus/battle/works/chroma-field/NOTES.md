# Chroma Field 笔记

## 我怎么理解这道题
题目要的是一个“渐变网格作品的工作台”，不是一张海报。所以我把界面分成两部分：
- **炭灰色外壳**：顶栏、带点阵底纹的画布区、裁切角标、状态栏、右侧检查器。
- **作品本身**：画布里一大块会动的暖色场（珊瑚、长春花蓝、洋红），上面压着半透明的超大衬线字 “Soft collisions.”。

我把 “soft collisions” 当成交互的核心来做。色团是带弹簧和阻尼的软体，彼此之间会柔和地碰撞、挤开。光标准星本身也算一个物体，拖着它穿过色场时会把颜色推开，色团会按速度方向略微拉伸变形，松手后再慢慢流回原位。

## 关键技术决策
- **模糊径向渐变**：10 个 DOM 色团，每个是 `radial-gradient(closest-side …)` 加 `filter: blur()`。只改 `transform` 来移动它们，所以模糊层只需要光栅化一次，拖动时开销很低。其中两个“暗影”色团用 `multiply` 混合，用来压出纵深。
- **data-URI SVG 湍流纹理**：一共两层。
  - 细颗粒层：`feTurbulence fractalNoise`，以 220px 为一块平铺，用 overlay 混合。
  - 丝绸般的低频层：各向异性的 baseFrequency，用 soft-light 混合，整张铺满（不平铺）。
  - 两层的强度都由 Grain intensity 控制。
- **光**：由三部分组成。
  - 一个 soft-light 光晕和一个 screen 高光核。
  - 准星带坐标标签，靠近边缘时标签会翻到另一侧。
  - 字的阴影方向和轻微视差都跟着光的位置变化。
- **文字**：两层叠加。一层 overlay 混合的半透明填充，一层 1px 描边的“玻璃边”。字号用容器查询单位 `cqw`，会随画布宽度缩放。
- **检查器**：
  - 3 个原生 `<input type="color">`，做成色块样式，并显示 HEX。
  - 光位置用原生 range 控件，水平、垂直各一个，带 `aria-valuetext`；另有强度滑块。
  - 小地图实时显示各个色团的位置，也可以直接在上面拖动光。
  - Grain intensity、Diffusion（模糊量）、Drift（流速）三个滑块。
  - 网格节点开关，打开后显示色团节点和连线；拖动时也会自动淡入。
  - “Reset everything” 和顶栏的 Reset 都执行完整重置：颜色、光、表面参数、色团位置和速度、时间、暂停状态、网格开关全部恢复。
- **无障碍**：
  - 画布可以获得焦点，方向键移动光，Shift 加速，Home 键让光回到中心；操作结果通过 aria-live 播报。
  - 暂停按钮带 `aria-pressed`。
  - 在 prefers-reduced-motion 下默认暂停。
- **字体**：从 npm 拉取 `@fontsource/instrument-serif`（正体和斜体）与 `@fontsource-variable/inter`，只取 latin 子集，base64 内联进页面。页面零网络请求，总大小约 166KB。
- **响应式**：
  - 宽度 ≤860px 时改为纵向排列：画布在上，高度 64svh；检查器在下，整页纵向滚动。
  - 画布设置了 `touch-action: none`，保证手机上可以拖动。
  - 顶栏在窄屏只保留图标按钮。

## 自测时发现并修掉的问题
1. 表面区的 Grain 控件显示成一团模糊。原因是 `.grain` 这个类名和颗粒覆盖层冲突，被套上了 overlay 混合和透明度，改名后解决。
2. 颗粒滑块的轨道看不见。原因是 `--fill` 里嵌套了 gradient，放进另一个 gradient 后失效，改成纯色。
3. 画面右侧 x≈900px 处有一条竖向接缝。原因是 900px 的丝绸纹理在平铺，而且没有无缝处理，改成用 viewBox 整张铺满。
4. 第一版色场偏粉、偏平，缺少纵深。我降低了提亮色团的白度，加深了底色，缩小并减弱了光晕，另外加了两个 multiply 暗影色团。
5. 用鼠标拖动时画布会出现焦点框。原因是在 pointerdown 里调用了 `focus()`，已去掉。
6. 网格连线太淡几乎看不到，改为实线虚线段并调高透明度，同时过滤掉距离太远的连线。
7. 重置后，开关在未选中状态下仍残留旧的强调色。去掉 background 过渡后，经复查正常。
8. 手机上文字偏小且贴着顶部，调整了字号和垂直位置。

每一轮都在 1400×875 和 390×844 两种视口下检查：
- scrollWidth 都等于 clientWidth，没有横向溢出。
- 控制台零报错、零警告，也没有网络请求。
- 拖动、方向键、滑块、改色、重置、暂停都通过脚本验证过。

## 自评
- **最满意**：把 “Soft collisions” 做成了真正的物理交互。色团之间会软碰撞，光也是一个会挤开颜色的物体，色团还会按速度拉伸。再加上会随光移动的字影和实时小地图，整件作品看起来是活的，而且有因果关系。
- **最不满意**：颗粒纹理在高 DPR 屏幕上的密度是按 CSS 像素固定的，在不同屏幕上的质感不完全一致。另外，默认色场在软件渲染下仍然偏柔和，饱和度不够浓烈。
