# Pelagia：笔记

## 我对题目的理解与取舍

- 题目的关键词是 **CSS jellyfish artwork**，所以水母本体完全用 DOM 和 CSS 画，不用 Canvas 或 WebGL：钟形伞盖、伞缘、内部器官、触手和口腕都是带渐变、阴影和遮罩的元素。JS 只负责两个控件，大约 60 行。
- 「Pelagia」对应夜光游水母（*Pelagia noctiluca*，俗称 mauve stinger），所以细节尽量贴近这个物种：伞盖上有刺胞疣点、放射管、四枚马蹄形生殖腺、中央口柄的光核、带感觉器小点的伞缘、8 到 10 条细长的缘触手，以及 4 条更宽、更柔的口腕。
- 三只水母的大小大约是 10 : 6 : 3.5。越小越远：透明度更低，最小那只还加了轻微模糊，做出景深。三只的脉动、漂移和摇摆各用一套周期和负延迟，所以相位始终错开，截任何一帧都不会同步。
- 左侧标题写成四行短诗：“Soft bells / *of the open deep,* / breathing light / *into the dark.*”。正体和斜体交替，并用缩进做出诗行的节奏。标题下是一句斜体引言，再下面用一条细分隔线引出控件。

## 关键技术决策

1. **生成静态标记**：触手是 15 到 17 节嵌套的 `<i>`，每节都绕自己的顶端旋转，旋转角度会一级级累加；每节的 `animation-delay` 按层级递增，于是一条波从根部传到末梢。这些嵌套标记由构建脚本一次生成并写死在 HTML 里，关掉 JS 水母也照样完整、照样在动。
2. **脉动与身体联动**：伞盖以顶部为原点做“收缩（变窄、拉长）→ 回弹 → 静止”的关键帧。触手群（skirt）用同一个周期做 `translateY + scaleX`，让触手根部始终贴着伞缘。另有一个 `bob` 层在每次收缩后把整只水母往上推，放松时再缓缓下沉，这是真实水母的推进方式。
3. **色相偏移**：用 `@property --shift` 注册成可以插值的数字。所有发光色都写成 `hsl(calc(268 + var(--shift)) …)`，拖动滑块时颜色会平滑过渡约 0.9 秒。器官色相比主色偏暖 28°，水体只跟随 18%，所以换色后海水依然是午夜靛蓝。读数显示色名（Lavender、Aqua、Rose…），`aria-valuetext` 同步更新。双击滑块可以复位。
4. **暂停和继续**：给 `html[data-play=paused]` 下的所有元素加上 `animation-play-state: paused`，时间轴原地冻结，恢复时不会跳帧。按钮带 `aria-pressed`，键盘 P 键也能切换。
5. **动效安全**：在 `prefers-reduced-motion: reduce` 下，纯 CSS 就会让所有动画停住（即使 JS 没有运行），JS 再把按钮设成“Resume”，由用户主动选择要不要动；色相过渡也会关掉。负延迟保证静止帧本身就是一幅构图完整的画面。
6. **离线字体**：用 `npm pack @fontsource/cormorant-garamond` 取得 Cormorant Garamond（SIL OFL 许可），只保留 300 正体、300 斜体、400 斜体三个拉丁子集，以 base64 内联，一共约 90KB。其余界面用系统无衬线字体栈。整个文件 137KB，没有任何网络请求（唯一出现的 URL 是 SVG 的 xmlns）。
7. **性能**：伞盖、光晕和触手群都加了 `will-change`，脉动只触发合成，不必重绘带大半径阴影的伞盖。粒子用径向渐变代替 `filter: blur`；颗粒噪点是静态的内联 SVG。

## 自测时发现并修掉的问题

- 390 宽度下 `scrollWidth = 468`，页面横向溢出：标题背后的暗色衬底伪元素超出了视口。已收窄衬底宽度，并给 `.scene` 加上 `overflow-x: clip`。
- 1400 宽度下第二行 “of the open deep,” 被拆成两行，破坏了诗行结构：放宽文字栏宽度，诗行改为 `nowrap`。
- 第一版的生殖腺是粗描边的马蹄形，看起来像一对卡通眼睛，整只水母成了一张脸：改为经过遮罩的柔和径向光环新月。
- 口腕第一版是一颗颗径向光斑，读起来像虚线；第二版的横纹又像梯子：最后改成中心高亮的丝带，只留极淡的褶纹。
- 缘触手向外张得太开，像一条裙子：把根部外张角从每 em 1.6° 降到 0.75°。
- 大水母漂到最高点时伞顶会被视口切掉：下移起始位置。
- 手机上按钮从 “Pause” 变成 “Resume” 后变宽，控件会换行；手机上最小的水母还压在引言和按钮后面：按钮改为固定最小宽度，滑块区允许收缩并收紧字距，同时重新摆放了手机上三只水母的位置。
- 844×390 横屏时，固定在角落的物种署名压到了引言上：视口高度小于 560px 时隐藏署名；标题字号加上 `11.5vh` 的上限。
- 用 Web Animations API 冻结时间轴，逐帧抽样检查了伞盖收缩、触手跟随和漂移，确认各部分连贯。

## 迭代轮数

一共 7 轮截图和修改（1400×875 与 390×844 每轮都截；另外测了色相偏移加暂停态、reduced-motion 态、844×390 横屏、1920×1080，以及逐帧序列）。最终两种视口下都没有横向溢出，控制台零报错，也零外部请求。

## 自评

- **最满意**：水母的“呼吸”。伞盖收缩、触手根部跟随伞缘、整体借收缩上浮再缓缓下沉，加上触手里一节节传递的波，全部是纯 CSS 关键帧，暂停后任何一帧也都成立。
- **最不满意**：口腕还不够“荷叶边”。真实夜光游水母的口腕是大片褶皱的半透明帘幕，我用分节丝带只能做出柔和的光带，做不出褶皱的立体感。
