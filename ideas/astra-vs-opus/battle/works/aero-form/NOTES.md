# Aeroform — 笔记

## 对题目的理解与取舍
- 「premium speculative sneaker design presentation」：我做成一份可滚动的 4 页「设计汇报 deck」（01 概念主视觉 / 02 结构分层 / 03 配色 / 04 状态声明），每页都有 `0X / 04` 页码和一个超大、低对比度的斜体背景词（Aero·form·Aeroform / Layers / Accent / Concept）。
- 视觉：整体用冷调云灰（#e3e6ea → #d9dde2），鞋身只用灰、白、深炭三种中性色，让一个强调色负责鞋侧的尾翼、后跟拉环、后跟气窗、鞋带头、鞋舌标签，以及页面上的按钮和下划线。
- 界面语言跟原题一致，用英文。

## 关键技术决策
- 纯内联 SVG 手绘鞋子（侧视、鞋尖朝右），整体 `rotate(-9°)`，摆成后跟着地的动态姿态，下方是两层模糊椭圆做接地软阴影，外加 7 秒的轻微悬浮呼吸动画。
- 部件：两种密度的网眼 pattern（后跟密孔、前掌菱形透气区）+ 明暗渐变叠层；后跟包片、鞋头护片（带打孔）、强调色尾翼 + 深色速度线、领口衬垫、内里针织纹、鞋舌与标签、远侧与近侧鞋眼片、7 对鞋眼、交叉鞋带（分上下层绘制）+ 蝴蝶结与鞋带头；中底分上下两层泡棉，中间有波浪分割线、雕刻凹槽、前掌屈曲纹、后跟强调色气窗（带肋条）和透明 TPU 后跟稳定片；外底是橡胶，侧壁有人字纹，底部是沿曲线排布的方形齿纹，鞋尖有包头。
- 重复细节（齿纹、人字纹、鞋眼、鞋带、打孔）用 JS 通过 `getPointAtLength` 沿引导路径生成，所以它们会自然贴合鞋底和鞋眼片的曲线。
- 爆炸图：鞋面、中底、外底是三个 `<g>`，放在旋转组里面，所以用 CSS transform 分离时会沿鞋子自身的竖轴移动。分离时还会出现虚线对位参考线、1/2/3 标注，下方显示图例；阴影同时收缩变淡。按钮带 `aria-pressed`，按 E 键也能切换。
- 配色：三套（Volt Drift / Ember Wake / Ion Tide）靠 `body[data-colorway]` 切换 CSS 变量，所有强调色部件用 `fill: var(--accent)`，不写进渐变里，这样颜色能平滑过渡。第 3 页的配色卡片是运行时把主视觉那只鞋克隆过去（去掉 id 和标注），每张卡片用局部 `--accent` 上自己的颜色；点卡片同样会切换主视觉，状态与顶部的色块按钮同步。
- 所有规格数字都带 “Imagined spec / Imagined” 标签；顶栏、首屏导语、规格表（价格栏写 “N/A not for sale”）、第 4 页的声明框和页脚都写明 “Not for sale”。
- `prefers-reduced-motion`：CSS 媒体查询关掉动画、把过渡时长压到接近 0，JS 也会同步加 `.rm` 类。
- 零外部依赖，只用系统字体栈，经测试零网络请求。

## 自测中发现并修掉的问题
1. 背景大字用了负 inset + nowrap，导致 1400 宽下 scrollWidth 变成 1543，出现横向溢出 → 给 hero 加 `overflow:clip`。
2. 鞋舌太高太圆，像棒棒糖；蝴蝶结过大 → 重画鞋舌轮廓，蝴蝶结缩到 0.74 倍。
3. 阴影离鞋底太远，看不出接地感 → 阴影上移，并在后跟下方加一块更实的接触阴影。
4. 爆炸标注的文字被 `.marker text{fill:#fff}` 盖成了白色 → 改用 `.n` 类，把选择器限定到数字上。
5. 标注 3 被底部控制栏挡住 → 移到后跟左侧，同时减小分离距离（鞋面 -104，外底 +54）。
6. 手机端 SVG 宽度设成 118%，后跟被裁掉 → 改为 106%，并在手机端隐藏两个会与鞋重叠的角标。
7. 鞋面和鞋舌的浅色边缘融进背景 → 各加一条半透明描边。

## 自评
- 最满意：爆炸图。三层部件沿鞋子自身倾斜的轴线分开，配上对位虚线和标注，而且配色卡片里的鞋是运行时从主视觉克隆出来的，三套配色能同时实时预览。
- 最不满意：鞋带交叉区是按平面侧视加一点俯视「假装」出来的，远侧鞋眼片和鞋舌的透视仍然偏平面化，离真正的 3/4 视角渲染还有距离。
