# The Hydraulic Balance：笔记

## 对题目的理解与取舍
- 题目要的是一件“安静的工业风科学展品”，不是游戏或仪表盘。我按博物馆展柜来布局：居中的衬线标题，中间是挂在带网格背板上的玻璃 U 形管，左右对称放两块表盘卡片（左边压差 ΔP，右边液位差 Δh），底部是通栏控制台。
- 物理只用一个静力学关系：Δh = ΔP / (ρg)，ρ = 1000 kg/m³，g = 9.81 m/s²。滑块是有符号的，ΔP = P_A − P_B，范围 ±2000 Pa，步长 10 Pa。B 口通大气，A 口施压：正压时左液面下降、右液面上升，负压（抽吸）时反过来。两臂内径相同，所以每个液面各移动 Δh/2。
- 读数全部显示最终平衡值（Pa、kPa、m、mm，还有左右液面各自的位移）。液柱和 Δh 表针会有一点轻微的欠阻尼回落（ζ≈0.76），这样看起来像真的水；设置了 prefers-reduced-motion 时直接跳到结果。
- “Schematic model” 披露用原生 `<details>` 实现，按钮名为 Model notes，打开后是一张向上展开的卡片，列出所有理想化假设（固定 ρ/g、等径、忽略毛细/表面张力/空气柱重量、表压）。点空白处或按 Esc 可以关闭。
- 首屏预置 +1200 Pa，让人一眼就看到液位差；Reset 回到 0 Pa（平衡位置）。

## 关键技术决策
- 单文件，纯手写 HTML/CSS/SVG/JS，没有依赖，也不发任何网络请求；字体只用系统字体栈（衬线用 Palatino/Charter/Georgia 一路回退）。
- 装置 SVG 按 1 单位 = 1 mm 绘制，刻度尺是真实毫米：每 5 mm 一小格，10 mm 中格，50 mm 标数字，背板用 5/25 mm 双层细网格。玻璃管用四层同路径描边叠出管壁和内孔，水柱用三层描边做出圆柱体的明暗，所以弯管处也连续。凹液面用二次贝塞尔曲线画，液面指针和虚线一直引到刻度尺上，中间有 Δh 尺寸线和数值胶囊。
- 两个表盘由同一个 JS 函数生成，结构和样式都对称：±135° 量程，带值弧、细刻度、数字窗和针尖色标。两个表的满量程是对应的（±2 kPa 对应 ±20.39 cm），所以两根针的角度总是一样。
- 控制台：自绘滑轨，从零点往两边的有符号填充用 CSS 变量驱动；推子式滑块帽；±50 Pa 微调按钮；键盘方向键、Home 和 End 都能用；aria-valuetext 会朗读压力和高度差。
- 窄屏（≤980px）把 `.stage` 设成 `display:contents`，重新排版成：装置 → 控制台 → 两块表并排 → 计算卡。手机首屏就能边拖滑块边看液面。

## 自测中发现并修掉的问题
1. 1400×875 下页面高 933px，控制台被挤出首屏。改法：副标题缩成一行，图注缩短，装置高度改成跟 dvh 联动，最后正好 875。
2. 1280×720 溢出 12px。调整了矮屏媒体查询里的高度公式。
3. 滑块刻度条上加了 `mask`，把两端的 “−2000/+2000” 裁掉了，已去掉。
4. 手机上两块表的标题一个折行一个不折，不对称。窄屏改用短标题 PRESSURE / HEIGHT。
5. 一开始手机上用了 sticky 底栏，但 Playwright 截全页时它会停在页面中间、压住表盘。改成上面说的 display:contents 重排，不再用 sticky。
6. 用 `:last-of-type` 选第二块表时误选到了计算卡，改用显式类名。
7. 铭牌文字字距太大，贴到了铆钉上；表盘里 “cm H₂O” 的下标在回退字体里显示成 “H,O”，改成 “cm”；水柱的三层条纹太硬，弯管高光的弧线也不同心，都重画了。
8. 回落动画原来 ζ=0.62，过冲偏大，不够“calm”，提高到 0.76。

检查结果：1400×875、390×844、1280×720、1024×768、820×1180 都没有横向溢出，控制台零报错，零网络请求。滑块键盘操作、±50 按钮、±2000 Pa 边界和 Reset 的数值都逐项核对过（例如 −1990 Pa 时左 +101.43 mm、右 −101.43 mm、Δh −202.85 mm）。

## 自评
- 最满意：装置 SVG 按 1:1 毫米绘制，刻度、凹液面、Δh 尺寸线和两块对称表盘的针角联动，读数能跟图形对上，经得起较真。
- 最不满意：桌面端受高度限制，U 形管只有约 490px 高，没能成为更压倒性的视觉主角；手机上表盘里的小字也偏小。
