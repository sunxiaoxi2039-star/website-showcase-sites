# Ink Finds Its Edge：创作笔记

## 对题目的理解与取舍

- 核心是“水彩墨晕”，不是“半透明圆”。我把它拆成几个能看出来的特征：波浪状的不规则边缘、边缘积色（颜料被水带到边缘，干后留下深色轮廓）、中心变浅、颜料颗粒沉进纸纹，还有扩散时内部留下的潮线（back-run）。
- 纸是暖象牙色。它不是纯色背景，而是有冷压纸的纸纹、零散纤维，光从左上方来，边缘带一点暗角。颜料用 multiply 叠在纸上，所以纸纹会自然透过墨色显出来。
- 排版要“大、留白多、黑色、现代 + 意大利体衬线”。我选了 Didone 类（排版分类里就叫 “Modern”）的 Bodoni Moda：正体 “Ink finds / edge.” 夹一行意大利体 “its own”。小标签用 500 字重、全大写、加宽字距。字体从 npm 拉下 @fontsource/bodoni-moda，取 latin 子集的 3 个 woff2，以 base64 内联，一共约 46KB。
- 开场按追加要求处理：页面加载时直接画出两朵已经完全展开的靛蓝墨晕（第一帧就是完成状态，不播动画），放在右侧，一大一小，互相叠压，叠压处更深。横屏和竖屏各有一套构图参数。
- 减少动态效果：`prefers-reduced-motion: reduce` 时，新墨晕直接以最终半径画出并烘焙到画布，“Fresh paper”也不做淡出，CSS 过渡同时关闭。系统设置变化时实时跟随。
- 界面语言用英文，和原题一致。

## 关键技术决策

1. **墨晕几何**：采用递归多边形变形（类似 Tyler Hobbs 的水彩做法）。基础形状是 30–40 个顶点的圆，叠加若干低频和中频谐波（形成大叶瓣和波浪边），再做轻微拉伸；每个顶点带一个“粗糙度”，沿圆周平滑变化，让有的边段平静、有的边段毛糙。每朵墨晕由 28 层各自再变形的多边形叠成，另有偏心的积色层（pool）和 1–3 条潮线。
2. **着色**：每层用径向渐变填充，中心淡、边缘浓；再用 `source-atop` 沿各层轮廓描深色边，只画在已有颜料上，所以边缘清楚、不外溢。潮线先用 `destination-out` 提亮内部，再描一圈深色脊线。最后叠两张可平铺的噪声纹理：`destination-out` 做云状斑驳，`source-atop` 做颗粒沉积。颗粒纹理和纸纹共用同一张噪声，并按屏幕坐标对齐，所以颜料确实沉在纸纹的凹处。
3. **扩散动画**：顶点位置 = 中心 + 最终偏移 × e^(1+lag·k)，其中 e 是 easeOutCubic，lag 是随角度平滑变化的谐波。效果是湿润的前沿在某些方向跑得快，形成波浪状推进，最后收拢到最终形状。颜料浓度从“集中在中心”过渡到“迁移到边缘”，边缘积色和潮线在后半段“干燥”时才显现。部分点击会随机甩出 1–2 滴延迟出现的小飞溅。
4. **分层合成**：纸一张 canvas；已干墨晕烘焙进 dry canvas；正在扩散的墨晕每帧重画到 wet canvas。两张墨层都用 CSS `mix-blend-mode: multiply` 叠在纸上。扩散结束后用 canvas 的 multiply 烘焙进 dry，没有活跃墨晕时不跑 rAF。
5. **性能**：扩散中的墨晕用降低的分辨率渲染（水迹本来就软），t > 0.9 时切回全分辨率；DPR 上限为 2；形状按 seed 缓存，改变窗口大小时按视口比例重新烘焙。
6. **交互与可访问性**：用 Pointer Events 统一处理鼠标、触摸和多指操作，`touch-action: none`。三个色板是 radiogroup，支持方向键，也有快捷键 1/2/3、R 重置；画布可以获得焦点，按 Enter 或空格在随机位置滴墨。光标是当前颜料色的小圈。色板里的小圆点也由同一个墨晕引擎渲染。

## 自测中发现并修掉的问题

- 第一版的高斯位移没有上限，出现了尖刺、碎片状的灰色多边形。改为给每次细分设位移上限，并降低层间变形幅度。
- 扩散中途墨晕像海星：lag 指数太大（2.8），降到 1.2。
- 墨晕轮廓发“多边形感”，像饼干：基础顶点从 8–13 个增加到 30–40 个，加入谐波叶瓣和中频波纹，并随机拉伸。
- 边缘发虚，有灰色光晕：描边改为在全部填充之后用 `source-atop` 统一描一遍，同时收紧各层的尺寸差异。
- 试过“纯色填充 + 一次 destination-out 渐变”来提速，但边缘积色明显变弱，最后回退到每层径向渐变，改用降低湿态分辨率、隔层描边来省性能。
- 纸纹颗粒太大太显眼，像迷彩：改成更细的噪声，并降低不透明度。
- 移动端初始墨晕太大，压住了文字：竖屏另设构图参数，同时加大移动端标题字号。
- “Fresh paper”淡出期间点击会生成墨晕，随后被清掉：淡出期间忽略点击和 Enter。

## 自评

- 最满意：边缘积色、潮线和颗粒都绑定在同一套纸纹上，放大看像真实的水彩；两朵开场墨晕叠压处自然加深，和大号 Bodoni 标题的构图比较稳。
- 最不满意：每帧重画整朵墨晕，在无 GPU 的软件渲染下，多朵同时扩散会明显掉帧（真实设备应该没问题，但低端手机仍有风险）。另外，干透后的边缘外侧还是留有一圈很淡的软晕，不如真实纸上那么锐利。
