# Abyss — 笔记

## 对题目的理解与取舍
- 题目要的是一张“电影感”的深海声呐研究控制台，而不是一个游戏。我把重点放在三件事上：一眼就能读懂的三栏构图（左：任务与深度，中：大雷达，右：目标分析）；雷达本身要有真实 PPI 显示器的质感；三个信号按钮要真的“揭示”东西。
- 三个信号按钮上只写频段（10–60 Hz / 4–20 kHz / < 5 Hz），不写名字。按下后才解析出目标：雷达上出现锁定框、方位线、距离环和标签，右栏给出名称、方位、距离、深度、频率、信噪比、多普勒、瀑布图、置信度和分析员备注，左栏深度剖面同时高亮该目标所在深度。这样“揭示”这个动作有实际分量。
- 三个虚构目标各有自己的声学“性格”：Lantern Choir（生物、脉冲和声、有谐波）、Iron Psalm（海床上的静止船体、窄带单音加整数次谐波）、The Tall Silence（异常目标：宽带噪声里出现一个“空洞”，只剩 3.1 Hz 的缓慢起伏）。第三个目标整个界面切换为琥珀色强调色。
- “艺术模拟”的标注放了三处：顶栏琥珀色徽章、雷达内的 SIMULATED FEED 水印、页脚完整声明（船名、海域、所有目标均为虚构）。
- 界面语言用英文，与原题一致。

## 关键技术决策
- 纯原生 HTML/CSS/JS，零依赖、零网络请求；字体用系统字体栈，颗粒噪点用内联 SVG data URI。
- 扫描扇区用 conic-gradient，由 JS 每帧写入 rotate。扫描角度就是唯一的时钟：目标和海底杂波的亮度按“距上次被扫过的角度”指数衰减，扫描线越过目标方位时才把目标位置“涂”上屏，并留下历史航迹点，读数也在这一刻闪烁更新。这就是真实 PPI 的余辉逻辑，雷达显得“活”，而不是简单的旋转贴图。
- 目标在基准点附近做缓慢小圆周漂移，所以方位和距离读数会随每圈扫描轻微变化。
- 频谱瀑布用 canvas，按对数频率轴（1 Hz–24 kHz）逐行生成（ImageData 写一行，再 drawImage 自身下移一行），并用 LUT 着色；异常目标使用琥珀色 LUT，并有“静默带”。切换目标时整幅预填充，避免出现空白画面。
- 暂停/继续：真正取消 requestAnimationFrame（扫描、瀑布、目标漂移全部冻结），按钮带 aria-pressed，状态同步到顶栏和雷达角标。页面隐藏时也停止循环。
- 键盘：原生 button + aria-pressed，另有快捷键 1/2/3 和 H，并加了跳转链接、:focus-visible 焦点环，以及 aria-live 播报（切换目标、暂停/继续）。雷达的 role=img 标签会随选择动态更新。
- 减少动态效果：同时响应 CSS 媒体查询和 JS matchMedia（监听变化）。开启后不运行动画循环，扫描扇区静止停在所选目标刚被扫过的位置（目标完全点亮），状态显示 “Static view”；关闭脉冲环、锁定框旋转、文字乱码解码、闪烁和颗粒层。
- 响应式：>1180px 三栏，在 1400×875 下面板基本落在首屏内；760–1180px 雷达独占一行，两侧面板在下方并排；≤760px 单列，雷达和按钮排在最前，角标精简。

## 自测时发现并修掉的问题
1. 390px 下横向溢出（scrollWidth 417）：原因是旋转中的扫描层方形包围盒超出视口。改为把扫描层包进 overflow:hidden 的圆形容器里。
2. 桌面左栏过高，把页面撑到 1075px：压缩标题、正文、任务条目，把深度剖面 SVG 从 226 改到 176 高，页面降到 942，三栏在首屏内收尾。
3. 初始航迹点顺序反了（最早的点被当成最新的），已修正。
4. “Resume scan” 文案变长时挤压信号按钮，导致频段文字被截断：给暂停按钮设最小宽度，并把频段文案缩短。
5. 瀑布图的频率标记用的是整条虚线，正好盖住 9.74 kHz 的主谱线：改成顶部短刻度。
6. 异常目标的静默带几乎全黑，看着像渲染出错：提高了残余噪声底。
7. 深度剖面里选中目标的标签超出 SVG 右边界：重新安排三个目标的 x 位置，引线只画在菱形左侧。

## 迭代轮数
共 5 轮截图迭代（r1–r5），覆盖 1400×875、390×844、1400×875 reduced-motion 以及 1024×768 四种情况；每轮检查 scrollWidth、控制台报错和外部请求，最终 0 报错、0 外部请求、无横向溢出。

## 自评
- 最满意：扫描线与目标余辉、航迹、读数刷新的联动。雷达像一台真的在“听”的仪器，三个目标在声学上也各有辨识度（尤其是 Tall Silence 的静默空洞和琥珀色切换）。
- 最不满意：依赖系统字体，在没有 Inter/Avenir 的机器上标题和正文会回落到 DejaVu 一类字体，细体标题的精致感打了折扣；在 1400×875 下页脚仍然在首屏之外。
