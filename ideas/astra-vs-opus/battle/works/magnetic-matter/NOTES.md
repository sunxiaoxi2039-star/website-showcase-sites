# Feel the pull — 笔记

## 对题目的理解与取舍
- 核心是“磁方向场”：满屏短罗盘针，每根按两个点磁极（source / sink，即 Gilbert 磁荷模型）的合场方向独立转向。颜色严格限定焦橙 / 赭黄 / 深石墨，画布用浅赭黄纸色。
- 左侧窄橙色控制栏：超大、紧字距（-0.065em）的 900 字重无衬线 “Feel the pull.”，其余全是控件和说明。题目是英文，界面用英文。
- 被拖动的只有一个极（虚线环标记 + 标签 “DRAG ME”），另一个固定。水平位置滑块与拖动同步，拖动可在二维自由移动。
- “Visual strength” 明确定义为只影响针的长度与墨色（对数增益曲线），不是物理强度；说明框写明这是平面上的点极近似，真实磁铁是有体积的三维偶极子。
- 手机端把左栏拆成“标题 / 画布 / 控件 / 说明”的纵向顺序（`display: contents` + flex order），保证打开就能看到画布。

## 关键技术决策
- 纯 Canvas 2D，无第三方库。场公式 `B = Σ q (r − p) / |r − p|³`，带小软化项，长度按 min(W,H) 归一化，所以不同屏幕的视觉强度一致。
- 针为双色菱形（橙色一端指向场方向，石墨一端反向），按墨色分 8 桶合并成 Path2D 批量填充，1700 根针一帧只有十几次 fill。
- 静态层（纸色、极点晕染、RK2 积分的背景场线、上下标尺及活动极 x 标记）缓存在离屏 canvas，只在变化时重绘。
- 针角度用指数缓动追目标，全部收敛后停止 rAF（静止时零 CPU）。首次加载针从“未磁化”乱向摆正；反转极性时从活动极向外按距离延迟形成涟漪，180° 翻转统一朝一个方向转，避免乱转。尊重 prefers-reduced-motion。
- 鼠标悬停时画一条穿过指针的场线和一个探针罗盘，右下角实时显示相对 |B| 与方位角。
- 高 DPI：canvas 按 devicePixelRatio（上限 3）缩放，监听 DPR 变化与 ResizeObserver。
- 无障碍：原生 range 滑块（带 aria-valuetext）、aria-pressed 的反转按钮、画布区域可聚焦后用方向键移动极点（Shift 加速）、R 键反转，aria-live 播报极点位置。
- 竖屏画布默认把两极摆成对角，避免挤在一起。

## 自测中发现并修掉的问题
1. 六边形错位网格的偏移公式写错，奇偶行没有错开。
2. 首次 resize 用了 snap，把“针摆正”的开场动画吃掉了。
3. `h1 span{display:block}` 把句号单独挤成一行。
4. 桌面 1400×875 下左栏内容溢出（说明框被截），压缩标题、提示与说明文字，把“Moving/Fixed”芯片并入顶部徽标。
5. “Reverse polarity” 按钮文字折行，改为不换行并收紧字距。
6. 手机端两极标签互相重叠、与 “Drag me” 提示气泡打架：重写标签布局（优先背离另一极一侧，依次尝试对侧/下/上，避开极点圆盘和已放标签），删掉多余的气泡。
7. 手机画布上的标题与针重叠难读，加半透明纸色底；图例与读数框缩小；无悬停设备显示 “tap the field”。
8. 键盘提示行横向溢出，缩短文案。
最终 1400×875 与 390×844 均无横向溢出，控制台零报错，拖拽、滑块、键盘、反转均验证过。
