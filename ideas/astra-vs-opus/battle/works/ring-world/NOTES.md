# Ring World — 创作笔记

## 对题目的理解与取舍

- 题目要的是一幅“行星肖像”，不是一个工具页面：画面要疏朗、居中、克制。所以版式按“科学图版”来做——顶部是小号大写的 Plate 编号加一个居中的大号衬线 “Saturn”，中间是星球，四周是细线引出的小注释，底部是三格仪器坞（视角 / 仰角仪 / 实时读数）。整页只用墨蓝加一种淡金色做点缀。
- “stylized and not to scale” 放在图注里，是紧贴画面下方的一块独立标签。画面本身也确实做了夸张：Cassini 缝和 Encke 缝加宽了，星空和配色也是艺术化处理。
- 视角滑杆范围定为 ±35°：地球上能看到的土星环最大开角约 ±26.7°，这个值在刻度上标成 “Earth max”；0° 是环面穿越（edge-on）。滑到负角时视点在环面下方，太阳仍在北侧，所以看到的是**背光面**：致密的 B 环变暗，稀薄的 C 环和 A 环反而透光发亮。这一点做成了真实的物理状态切换，读数和仪表会同步显示。

## 关键技术决策

1. **环是按层叠的径向渐变 + 重复径向渐变来定义的**。D、C、B、Cassini、A、F 每个环各是一层：一条径向渐变底色（控制亮度和不透明度随半径的变化）叠上若干条 repeating-radial-gradient（小环纹、密度波），再用环带遮罩把 Maxwell、Encke、Keeler 等缝挖掉，语义和 CSS 的写法一一对应。最外面还有一层淡淡的 G 环 / E 环尘埃平面，直接用 CSS 的 `repeating-radial-gradient` 画，再用 `scaleY(sin B)` 压成椭圆。
2. **主环最后交给 Canvas 逐像素光栅化，并做各向异性过滤**。所有层先合成为一条一维径向剖面，存成前缀和（积分）表。每个像素按它在环面上覆盖的径向宽度取盒式平均，所以环面压扁时，细纹会自然融合，而不是出现摩尔纹或锯齿。环面按远/近两半分别画到星球下方和上方的两张 canvas 上，遮挡关系由此自然成立。
3. **星球是逐像素着色的扁球体**（极半径/赤道半径 = 0.902）：用射线求交得到法线和纬度，按纬度查条带表，再叠上随经度起伏的细纹、Minnaert 式临边昏暗、暖色晨昏线、北极六边形和南极涡旋，夜侧加一点环光。
4. **阴影都是算出来的，没有手绘**：环在星球上的投影，是从表面点沿太阳方向与环面求交，再查环的透过率；星球在环上的投影，是用阴影圆柱与环面相交的椭圆式判定（w² + (u·sin e / b_e)² < 1），落在背阳一侧。太阳设在左前方、环面上方 12°，所以默认视角下，环影会露在前环内缘上方的星球表面，星球的影子会切过右后方的环。
5. 注释锚点跟着 3D 几何投影走，会做遮挡检测（被星球挡住的锚点显示为虚线）。“环影”锚点是在星球上扫描出真正可见的阴影段后再定位。标签在左右两列里按锚点高度做一维防重叠排布。窄屏改成编号圆点，下方配图例。
6. 交互：滑杆、键盘方向键、鼠标在画面上竖向拖动、预设按钮（缓动过渡）、Sweep 自动扫角。拖动时先以低分辨率渲染，停手 160 ms 后再补一帧全分辨率。
7. 零依赖、零网络请求：字体用系统衬线栈（Iowan / Palatino / Charter / Georgia），favicon 用 `data:` URL。

## 自测中发现并修掉的问题

- 第一版的环是 12 个 CSS 层（重复径向渐变），整体做 `scaleY`。截图放大后发现，环面前后缘的细纹有明显的摩尔纹，椭圆边缘也有台阶状锯齿。原因是浏览器在压缩方向上按点采样，不会做滤波。于是改成“渐变层定义 + 积分表各向异性过滤”的 Canvas 光栅化，问题彻底消失。
- 星球在环上的阴影，第一版是一个旋转的 CSS 椭圆块，边界和位置都不准；改成逐像素解析判定。
- 第一版太阳仰角约 22°，和默认视角几乎重合，环影正好藏在前环背后，“Ring Shadow” 注释因此找不到锚点。把太阳仰角降到 12° 后，环影露了出来；同时把锚点检测放宽为允许透过半透明的 C 环看到阴影。
- 环影落在星球上时，C 环 / Cassini 的细结构在掠射角下有锯齿。给阴影透过率表加了一个小窗口平滑（模拟半影）来解决。
- 1400×875 下仪器坞原本被挤到首屏以外：去掉装饰分隔线，标题字号改为按 vh 限制，舞台高度改为由“视口高度 − 标题 − 仪器坞”反推行星半径；±35° 极限角时环恰好不压到标题和图注。
- 1024 宽时注释文字换行后互相重叠：数据行改为不换行，并要求两侧至少留出 242px，不够时缩小行星。
- 移动端注释的 6 号和 7 号圆点重叠：把 Encke 锚点挪到 38° 方位角。尘埃平面比舞台宽，导致 390px 下出现横向溢出（scrollWidth 450）：给舞台加上 `overflow-x: clip`，并在窄屏隐藏尘埃层。
- 仰角仪的 ±45° 刻度文字被裁切，+15° 的刻度字和太阳图标重叠：改为只标 0° 和 ±30°。
- 背光面第一版只是整体变暗；后来按光学深度重新定义散射亮度与不透明度，B 环暗下去、C/A 环透亮，才像真正的背光土星环。

最终在 1400×875、390×844 下均无横向溢出（scrollWidth 等于 clientWidth），控制台零报错，零外部请求。1024×768 和 1920×1080 也检查过。

## 迭代轮数

共 **8 轮**截图-修改循环：CSS 版初稿 → Canvas 光栅化重写 → 太阳角 / 首屏布局 → 仰角仪 / 背光面 → 中等宽度与移动端 → 性能（交互降分辨率）→ 尘埃平面 → 溢出修正与终检。

## 自评

- **最满意**：环的质感和物理一致性。细密的小环纹在任何倾角下都不闪烁；环影、星球影、背光面、环面穿越都由同一套几何和同一条径向剖面推出来，拖动滑杆时每一处细节都“对得上”。
- **最不满意**：主环的最终像素是 Canvas 光栅化出来的，不是浏览器直接绘制 CSS `repeating-radial-gradient`（只有最外层尘埃平面是纯 CSS）。这是为了消除摩尔纹做的取舍，但在“字面上”离题目更远了一步。另外，在 CPU 很紧张的环境里，拖动时逐像素重绘仍有轻微卡顿。
