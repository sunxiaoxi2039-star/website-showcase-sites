# Suspended Balance — 笔记

## 对题目的理解与取舍
- 核心是「中世纪（1950s）动态雕塑习作」：暖白画廊墙 + 细黑钢丝 + 四块纯色平涂金属片（赤陶椭圆、赭黄三角、青绿半圆、深橄榄圆盘）。我按 Calder 式三级级联来构图：长臂单挂赤陶椭圆作配重，短臂下挂第二根梁（三角），再挂第三根梁（半圆 + 圆盘）。
- 滑块只控制主梁绕悬挂点的转角；下面两级梁以「同情式」的延迟摆动回应（手调的弹簧与比例），明确不做力矩计算。页面在正文与「A note on method」中直接声明这是艺术习作而非物理模型。
- 界面语言按原题用英文；字体只用系统衬线栈（Iowan / Palatino / Charter / Georgia …），零网络请求。
- 状态 = 角度数值 + 状态词（Poised / Leaning / Tilting / Reaching / At the edge）+ 一句描述哪边下沉的文字，同时写进滑块的 aria-valuetext。

## 关键技术决策
- 单个内联 SVG。主梁用 `rotate(a, 悬挂点)`；吊线和下级梁的挂点由 JS 用三角函数算出，保证所有吊线始终竖直（这是「挂着」的视觉关键）。
- 墙上投影：`<use href="#mobile">` 复用整组图形 + 模糊/着色滤镜，一份几何两处显示，自动同步。
- 顶部吊线延伸到画面外，由 plate 的 overflow 裁切，看起来从天花板垂下。
- 细节：钢丝 `vector-effect: non-scaling-stroke` 保证手机上依然清晰；梁两端的小环、枢轴压接点；绘图员式的虚线水平基准 + 角度弧与读数。
- 形体缓慢做 scaleX 变化，模拟金属片在空气中转动；再叠一层极轻的「微风」。提供「Still the air」按钮可随时静止（WCAG 2.2.2）。
- 可直接在画面上拖动主梁（指针捕获，SVG 坐标换算），与滑块双向同步。
- 减少动态：`prefers-reduced-motion` 时不启动 rAF，所有臂直接落到目标角度、形体不转动、CSS 过渡全部关闭，并实时监听系统设置变化。
- 布局：≥940px 左侧墙面 sticky 满高、右侧目录式文字栏；窄屏改为 标题 → 作品 → 控制 → 导语 → 说明，使 390×844 首屏就能看到滑块。

## 自测中发现并修掉的问题
1. 第一版作品在画面里偏小偏上、下方大片空白 → 收紧 viewBox 并下移构图，缩短圆盘/半圆吊线。
2. 角度标注文字压在主梁上 → 改为放在水平基准线远离梁的一侧。
3. 状态句语法错误（"The cascade swing low"）→ 重写为完整主语。
4. 天花板小吊座及其投影显得突兀 → 改为吊线延伸出画面。
5. 手机上聚光灯渐变在 plate 顶部形成硬边 → 改成中心向四周完全淡出的径向渐变。
6. 手机首屏看不到滑块 → 导语拆成独立 grid 区域，窄屏移到控制区之后；隐藏窄屏上多余的键盘提示与重复角度读数，作品区左右不留内边距以放大图形。
7. 「0°」时文案说"每根臂都水平"但下级臂有 ±2.5° 的构图偏角 → 文案改为只描述主梁。
8. 减少动态模式下禁用按钮样式发黑 → 单独给禁用态虚线描边样式。

## 迭代轮数
共 4 轮截图迭代（1400×875 与 390×844 各截静态、+22° 两种状态，手机另截全页），外加 1 轮减少动态 / 键盘 / 静止按钮 / 拖动专项测试。最终：两种视口无横向溢出，控制台零报错，零外部请求。

## 自评
- 最满意：吊线始终竖直的级联结构 + 下级臂延迟摆动 + 墙面投影，一拖滑块就有「挂在空气里」的感觉，同时整体仍是克制的平涂中世纪调子。
- 最不满意：手机上整件作品只有约 360px 宽，形体偏小，角度标注文字很小；没有为竖屏单独设计一套更紧凑的构图。
