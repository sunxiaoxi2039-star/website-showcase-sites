# Prism Studio · 创作笔记

## 对题目的理解与取舍

- 核心画面是「白光入射三棱镜并以宽阔六色光谱射出」，要电影感：近黑舞台、克制的辉光（bloom）、大号细体排版、极简控件。
- 「滑块必须旋转入射光与出射光」——我没有只让光束做装饰性旋转，而是用真实的斯涅尔定律（矢量形式）逐色追迹：入射角变化时，入射光绕入射点转动，六条色带各自按折射率重新计算出射方向，偏向角、色散角也随之变化。
- 题目要求称其为 artistic interpretation：页面标题区、右上角元信息都明确写出，并说明色散被夸大（n 取 1.49–1.60，约为真实冕牌玻璃的 6 倍）、不按比例。
- 界面语言按原题用英文。标题 “Dispersion”，Inter 可变字体 weight 100。

## 关键技术决策

- **纯 CSS 渲染，无 canvas / WebGL**：所有光束、棱镜面、边线、光斑都是全屏 `<i>` 元素 + `clip-path: polygon()/circle()` + `radial/linear/conic-gradient`，完全对应题目的 “CSS clip paths, gradients”。JS 只负责几何计算，每次滑动只改 style 字符串。
- **辉光**：同一组形状画三层——清晰层、`blur(~10px)` 层、`blur(~44px)` 宽辉光层，全部 `mix-blend-mode: screen` 叠加；棱镜内部六色楔形用 screen 叠加自然合成白色，出射后逐渐分离。
- **光学模型**：60° 等边棱镜；入射面、出射面用矢量斯涅尔公式；光束有宽度（两条边缘光线分别追迹）；小入射角时短波先发生**全反射**，被反射的色带在玻璃内部射向底面，状态栏与色块提示哪些颜色被全反射。
- **色带“再平铺”（艺术处理）**：真实宽光束的六色在近处高度重叠会一片白。我让每条色带在靠近棱镜时保持物理宽度（重叠成白），在一段距离内用 smoothstep 平滑过渡为首尾相接的平铺，远处呈现干净、连续的宽光谱；同时保证扇面不会窄于光束本身。
- **标注**：入射点处有虚线法线 + `conic-gradient` 遮罩成的角度弧 + θᵢ 读数；色带末端在可视区域边缘标出 700–410 nm（太密时只标两端）；滑块上标出黄光最小偏向角位置 “min δ”。
- **响应式**：竖屏（宽高比 < 0.85）时把整个光学台旋转 90°，光从上方落下、光谱向下展开，避免手机上棱镜过小；顶部加暗色渐隐遮罩保证标题可读；控制面板在手机上压缩为底部玻璃卡片。
- **离线**：Inter 可变字体（拉丁 + 希腊子集，用于 θ/δ）由 `npm pack @fontsource-variable/inter` 取得并 base64 内联；胶片颗粒是内联 SVG feTurbulence data URI；零网络请求。
- 支持键盘（原生 range）、`aria-valuetext`、`prefers-reduced-motion`。

## 自测中发现并修掉的问题

1. 第一次反射（菲涅尔）光束太长太亮，横穿标题 → 缩短到约半个棱镜边长并降低亮度。
2. 波长标签直接压在彩色光带上看不清 → 改为白字 + 深色阴影 + 色点；标签间距过小时只保留两端。
3. 全反射后已消失颜色的标签仍残留；色块/标签的 CSS transition 在无头截图中不可靠 → 去掉 transition，改为 display 切换。
4. 大入射角（78°）时光束在出射面上的足迹很宽，六色重叠导致整条光谱发白 → 引入色带再平铺。
5. 再平铺的第一版在过渡点出现明显折角 → 改为 10 个采样站点 + smoothstep 混合，边缘变成平滑曲线。
6. 标签可见性判断用了从棱镜起算的距离阈值，平铺后起点外移导致桌面标签全部消失 → 修正阈值。
7. 手机竖屏：入射光穿过标题段落 → 顶部渐隐遮罩（置于标注层之下，θ 读数不被遮）；面板过高挤占光谱 → 手机上隐藏刻度行与副标题，光谱更早分色。
8. 滑块 “min δ” 被 uppercase 变成 “MIN Δ” → 取消该处大写。
9. 入射角 30° 时绿光全反射，偏向角显示 “—” → 偏向角改为以黄光（≈钠 D 线）为参考。
10. 平板竖屏面板过宽 → 限制最大宽度并居中。

检查项：1400×875、390×844（另测 768×1024、844×390）均无横向溢出，控制台零报错、零外部请求；鼠标拖动与键盘方向键均能驱动光束旋转与读数更新。

## 自评

- **最满意**：光路是真实追迹的——拖动滑块时入射光、棱镜内光路、六条出射色带、偏向角与全反射都同步变化，小角度下蓝紫光在玻璃内部全反射的细节尤其有说服力；同时全部用 CSS clip-path + 渐变 + 混合模式完成。
- **最不满意**：色带远端的“再平铺”是艺术处理而非物理结果，大入射角时近处白色重叠区仍偏长；辉光在低端设备上拖动时的模糊重绘成本也偏高。
