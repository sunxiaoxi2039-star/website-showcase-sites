# 《宿建德江》CSS 水墨长卷：笔记

## 对题目的理解与取舍
- 题目的核心是“静观”和“纯 CSS 剪影”。所以所有山、日、水、舟、树、印都是 DOM 元素，用 `clip-path`、渐变、`border-radius` 和 `mask` 画出来，不用 canvas，不用 SVG，也不用图片。
- 选了孟浩然《宿建德江》作竖排诗：“移舟泊烟渚，日暮客愁新”。它正好对上题目里的舟、烟（雾）、日暮（红日）和江，诗和画是同一件事。界面按原题用英文，下方中栏附上我自己的英译。
- 构图取手卷式横幅（12:5）。左边是主峰群，中间是红日，右上是题诗、落款和白文印“山水清音”，左下有一枚小朱文闲章“烟波”，右下是前景礁石和墨点树。
- 三栏图注刻意做得克制：画题与出处、英译诗、Atmosphere（雾滑块）。滑块本身就放在第三栏里，不另外加控制面板。

## 关键技术决策
- **山体生成**：用确定性 PRNG 和分形值噪声，在“世界坐标”（宽 2.4、高 1）里定义各峰，峰形为 `(1-t^q)^1.55`，q 控制圆头还是尖峰。生成的 polygon 写进 CSS 变量 `--clip`，同一个变量同时给山体、墨线层、皴笔层和倒影用。
- **墨韵**：每层山分成三层叠放。底层是深色 edge，上面的 wash 层下移约 0.7%，于是露出一道随坡度粗细变化的“勾线”。再加一层 tex，里面是沿山脊向下的细笔（仿披麻皴），同样被 clip-path 裁在山内。脊上点苔点，前景有墨点树。
- **雾滑块**：只驱动一个 `--m` 变量，再加上每层山脚的消散深度 `--f`（越远的层散得越早）。它连带改变各层透明度、雾带、全局雾幔（强度按 m² 增长）、日的模糊与晕、倒影强度和日影。滑块分五档命名，从 Clear dusk 到 Sea of cloud，并带 `aria-valuetext`。
- **水面**：倒影是同一个 clip 以水平线为轴 `scaleY(-1)` 翻转，外层 mask 做渐隐，内层条纹 mask 把倒影切成细波纹，另有缓慢的 wobble。水面上还有随机细波光，日下方有一道断续的朱色光带。
- **响应式**：根据场景宽高比换“取景窗”。宽屏看整幅长卷；平板裁掉最左边一点；手机竖屏（5:6）改成立轴式取景，只取长卷右半部分（日、右侧峰群、前景松石），诗和印按 cqw 缩放。
- **字体**：本机没有楷体和宋体，所以从 npm 拉了 Ma Shan Zheng（毛笔楷）和 Noto Serif SC 900（印文），用 fonttools 按实际用到的字子集化后内联，共约 28KB。拉丁字用 EB Garamond 内联。整个文件约 174KB，零网络请求。
- **减弱动效**：`prefers-reduced-motion: reduce` 时停掉所有动画，舟停在江心，提示文字也会说明画面处于静止状态。

## 自测中发现并修掉的问题
1. 纸纹用了两组正交的 repeating-linear-gradient，放大后成了明显的方格纸，改成错位的 repeating-radial 细颗粒。
2. 苔点太大太匀，像波点，于是缩小、压扁，并集中到山脊线上。
3. 山峰早期是几何三角形，像剪贴画。改法是增加圆头小峰组成复合轮廓，再加皴笔层。
4. 右侧山峰穿过落款和印章，因此调整了峰群位置，去掉落款里的“唐”字，缩短了落款列。
5. 树先是“叠盘子”，后来又变成“天线”，最后改成墨点团簇树冠。
6. 小舟开场时透明度还在淡入，首屏截图几乎看不到，于是给动画加了负延迟，让舟一开始就在江心。另外重画了船篷、斗笠和人形。
7. 手机竖屏时，红日被印章压住、主峰被裁掉，改成取右半卷的立轴构图。平板上印章压到山峰，改为裁掉左侧一截。
8. 印文字号过大，溢出了印面，已缩小。

我在 1400×875、390×844、820×1180 和 320×640 四个视口，以及雾 0 / 42 / 70 / 100 和 reduced-motion 下都截图查看过：没有横向溢出，控制台零报错，没有网络请求。

## 自评
- 最满意：诗、画、印的统一。所选的诗本身就在写这幅画，竖排毛笔诗配白文印，雾滑块也能真正改变画面的气息。
- 最不满意：山体轮廓毕竟是多边形剪影，勾线粗细只随坡度变化，缺少真实水墨那种飞白和墨色的不均匀。近看仍有“矢量感”。
