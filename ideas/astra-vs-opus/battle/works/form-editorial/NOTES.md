# FORM — 创作笔记

## 对题目的理解与取舍

- 我把题目理解成“一张能读的杂志封面”：首屏（1400×875）本身就是完整的封面构图，不需要滚动。再往下是展开后的编辑来信，最后是版权页。
- **三栏不对称**：三栏比例是 2.05 : 4.35 : 3.3。A 栏放目录和一句引语，B 栏放封面故事的大标题、数据条、导语和“编辑来信”按钮，C 栏放雕塑。C 栏从报头那一行一直通到底，所以巨大的 FORM 报头只占左边约 2/3，右边的雕塑可以竖着长高。这是整个版面不对称的来源。
- **概念闭环**：标题是 “Nothing is ever just a circle.”，雕塑、文章和细节都围绕这句话展开：
  - 雕塑静止时读作“一个红色圆盘 + 一条轨道环”。hover 后，圆盘转成刀片，一条环散开成六条经线组成的球，黑球升起，背后的构造线圆弧被画出来。
  - 编辑来信写的是一篇真正有论点的短文。材料有乔托的 O（瓦萨里记载的故事，以及 *tondo* 这个词的双关）、欧几里得对圆的定义、字体设计里的 overshoot（报头 FORM 里的 O 本身就不是正圆）、报纸网点（半色调）、禅宗的圆相（ensō）。结论是“圆是一种约定”，并且和封面雕塑互相呼应。
  - 其他细节也是圆：页眉的套准标记、会旋转的圆形期号贴纸、雕塑下用半色调圆点画的投影，以及文章侧栏一笔画成、留有缺口的圆相。
- 杂志、艺术家、编辑都是虚构的，版权页里写明了这一点。

## 关键技术决策

- **单文件、零网络**：用 `npm pack` 拉下 Inter Tight（variable）、Instrument Serif（正体 + 斜体）和 Newsreader（variable，正体 + 斜体），只取 latin 子集，用 base64 内联。三款都是 OFL 授权，HTML 总大小约 330KB。纸纹用内联的 SVG feTurbulence data URI 生成。
- **报头**：`container-type:inline-size` 加 `font-size:37.7cqw`，字重 900，字距 -0.058em。报头始终刚好撑满它所在的栏宽，不依赖 JS。
- **雕塑**：纯 CSS 3D，在同一个 `preserve-3d` 上下文里，让轨道环真正从圆盘的前面和后面穿过。整个变形只由一个变量 `--t` 驱动（0→1），所有 transform 都写成 `calc(var(--t) * …)`，所以 hover、按钮和触屏点按共用同一套插值，没有重复的状态规则。圆盘由 5 层叠成，转到侧面时能看出厚度。雕塑的尺寸单位是 em，用 `min(100cqw/41, 100cqh/65)` 同时适配栏宽和栏高。
- **可访问性**：
  - hover 之外，另有一个 `aria-pressed` 的 “Turn it” 按钮，键盘和触屏都能触发变形；说明文字的状态区是 `aria-live`。
  - 编辑来信按钮用 `aria-expanded` + `aria-controls`，按钮文案会随状态切换。收起时内容区是 `hidden`，不进入无障碍树。展开后焦点移到文章标题（`tabindex=-1`），页面平滑滚动过去。文末的“Close the letter”按钮和 Esc 键都能收起，并把焦点还给触发按钮。
  - 支持 `prefers-reduced-motion`。
- **展开动画**：用 clip-path 做自上而下的“揭幕”，同时有位移和淡入；侧栏的圆相用 SVG mask 描边动画“一笔画出”。
- **手机端折叠**：B 栏改为 `display:contents`，重新排成“报头 → 标题 → 雕塑 → 数据 → 导语与按钮 → 目录”，让标题出现在首屏。数据条变成 2×2，页眉变成两行。1100px 以下还有一档两栏的中间布局。

## 自测中发现并修掉的问题

1. 报头字号偏大，M 冲进了 C 栏；中/小屏媒体查询里残留的旧字号还让手机横向溢出了 9px。改为统一使用 cqw 字号。
2. 纸纹噪点太重，看起来像砂纸，降低了不透明度。
3. 首屏放不下（页面高约 1075px）。做了三件事：标题从三行改成两行，压缩目录，把条码移到版权页，最终封面正好 875px 高。
4. 雕塑贴着栏底，上方大片留白。改为按栏的宽和高双向适配，并加了旋转的期号贴纸来平衡构图。
5. 最初用 grid-rows 0fr→1fr 做展开动画，导致展开后滚动时页面还没有长高，停在错误的位置。改成布局立即撑满、只用 clip-path 做视觉揭幕。
6. `.letter-clip` 上的 `overflow:hidden` 会让侧栏的 sticky 失效，删掉了。
7. 圆盘转到侧面时，前后两层之间有缝，看起来像两片刀。改为 5 层堆叠。
8. 圆相原本是一条均匀的描边，像个 C。改用 Python 生成一条宽度渐变、带颤动和飞白的笔触，并留出真正的缺口。
9. 手机上文章的元信息排在标题之前（被中屏的 `grid-row:1` 规则覆盖了），已修正。
10. 桌面端 hover 状态恢复的过渡过程中，出现过 4px 的横向溢出，在 `.sheet` 上加了 `overflow-x:clip`。
11. 1920 宽屏时 B 栏空隙过大，给封面的 min-height 加了 960px 上限；1024 宽时按钮被挤压，改为单列。

最终验证：1400×875 和 390×844 下都没有横向溢出，控制台零报错、零网络请求。展开/收起、Esc、焦点归还、触屏点按和 reduced-motion 都用 Playwright 测过。

## 迭代轮数

共 6 轮：初版 → 版面与首屏适配 → 雕塑重构、揭幕动画与圆相 → 数据条、贴纸与手机重排 → 中屏与宽屏 → 收尾修正。

## 自评

- **最满意**：概念闭环。标题、雕塑的 hover 变形（一个圆 → 六环球 + 刀片）、文章论点（O 的 overshoot、网点、圆相）互相指涉，而且雕塑的状态由一个 `--t` 变量驱动，写得很干净。
- **最不满意**：静止状态下，圆盘嵌在黑色半球里，更像“碗里的一个球”，“圆盘”的平面感还不够明确。另外，报头里 R 和 M 的笔画在紧字距下有轻微粘连。
