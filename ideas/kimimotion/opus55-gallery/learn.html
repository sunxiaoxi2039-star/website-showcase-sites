00 / HOW TO READ

这套整理怎么读

每个案例条目固定四件套：成片（视频）→ 风格 Prompt 全文 → 一句话读懂 → 涉及知识点。把鼠标悬停在知识点标签上，或翻到第一节「名词速通」看详细解释。读完前三节，你就拥有了改写任何风格的基本功。

01 / VOCABULARY

名词速通：Prompt 里出现这些词，分别在说什么

用「拍电影」打比方。一部代码影片的背后是一条流水线：有人写剧本（Prompt），有人搭景（HTML/CSS），有人指挥演员（JavaScript），有手绘动画台（Canvas）和 3D 摄影棚（three.js），最后由摄影师逐帧拍下来（Playwright），送去剪辑台合成（ffmpeg）。

一条代码影片的诞生流水线：
Prompt(剧本) → HTML/CSS/JS·TS(搭景+演员) → Canvas 2D(手绘台) / WebGL+three.js(3D摄影棚) → 浏览器(放映机) → Playwright(逐帧摄影师) → ffmpeg(剪辑合成) → mp4 成片
HTML
结构层

网页的骨架。告诉浏览器「这一页有哪些东西」：一个画布、一段字幕、一个按钮。Prompt 里出现它 = 产物是一个网页文件，不是视频工程文件。

CSS
表现层

网页的皮肤和服装。管颜色、字体、排版、圆角。出现它 = 对画面观感有具体规范（比如字幕用什么字体、多大字号）。

JavaScript (JS)
行为层

导演 + 演员 + 场务。所有「动起来」的部分都靠它：每帧画什么、什么时候出字幕、音乐在第几秒响起。这批案例 99% 的活都是 JS 干的。

TypeScript (TS)
工程层

带了「安全带和清单」的 JS。代码量大了以后防止手忙脚乱写错。Prompt 里出现它 = 这是一个规范的大工程，AI 会分文件、写类型。

Canvas 2D
2D 渲染台

手绘逐帧动画台。一支支笔触、一层层晕染都是在这块布上画的。水墨、水彩、版画风格的主力工具。

WebGL
3D 渲染协议

让显卡来画画的协议。浏览器里跑 3D、光影、水波的本质。它很底层，直接写很折磨——所以人们用 three.js。

three.js
3D 摄影棚

WebGL 的开箱即用摄影棚。相机、灯光、模型、材质一站式配齐。鹈鹕骑单车、赛车、运输船这些 3D 案例的主力。Prompt 里出现它 = 你要的是 3D 场景。

Shader 着色器
光影化妆师

跑在显卡上的小程序，专管「光怎么打」。水底的晃动的光斑、纸上的晕染，都是 shader 的功劳。Prompt 里出现 GLSL/shader = 要高级光影质感。

Blender
离线建模

专业 3D 建模软件（要安装的桌面程序）。注意：这批案例大多不用 Blender——模型是代码现场生成的。Prompt 里提到它 = 有预制 3D 素材，或需要导出模型文件。

Playwright / Puppeteer
逐帧摄影师

没有屏幕的浏览器，专职截图。代码每算出一帧画面（1/24 秒），它就拍一张照片存成 PNG。Prompt 里的「headless（无头）渲染」就是指它。

ffmpeg
剪辑合成台

音视频界的瑞士军刀。把几千张 PNG 连成视频、把配音配乐混成音轨、把响度调到广播标准。几乎所有案例的最后一步都是它。

TTS（Kokoro 等）
配音演员

文本转语音的 AI 配音。案例里的旁白就是它念的，「speed 0.93」这类参数是在调教它的语速和气质。

whisper
台词监工

语音转文字的校对员。配完音先让它「听写」一遍，确认 AI 配音没有把单词念错。案例里每个音节都过了这关。

librosa / 采样库
配乐师

分析音乐节拍 + 提供免版权乐器素材。案例里袋鼠跳跃精准踩拍，就是因为先用 librosa 分析了配乐的节拍网格。

LUFS / 响度
音量标准

广播级音量度量。「-14 LUFS」是 YouTube/B站 常见的响度目标，ffmpeg 的 loudnorm 负责一键达标。

seed / 确定性
复现保险

随机数的种子。给随机效果（比如笔触的抖动）固定一个 seed，每次渲染结果一模一样——这是「逐帧渲染」不闪烁的关键。

中国水墨 · Chinese Ink Wash

样片：The Swordsman and the River（48s，侠客踏水过江，一剑断流）

一句话读懂：整幅画只有宣纸、五色墨和一枚朱砂印。空白不是背景，留白本身就是水、天和 silence——最厉害的特效是「把墨迹擦掉」。

另一条路线：3D 交互案例（轩辕文章里的五个）

03 / PROMPT ANATOMY

解剖一段顶级 Prompt：水墨风格的九段结构

把水墨的 STYLE.md（全文约 5000 字）拆完，会发现它是一个可复用的九段式骨架。任何一个风格 Prompt——甚至任何「让 AI 做复杂作品」的 Prompt——都可以按这九段来写。点 这里 对照原文阅读。

① 风格定义

用参照系锚定审美：「像上美影《山水情》的留白语法 + 《卧虎藏龙》竹林的轻盈动作，但不抄具体画面」。给 AI 一个可查询的审美坐标，而不是空泛的「要高级」。

② 故事适配

列出这个媒介的「天生神力」清单（一笔成山/留白即水/飞白是高潮），规定「至少用三种，最强的放在情感峰值」。等于教 AI：这个风格适合讲什么故事。

③ 视觉语言

精确到色值：纸 #F2ECDE、朱砂 #B02E22、墨分五色各配不透明度；笔触模型=中心线×压力×笔毛断墨。把「好看」翻译成算法能执行的参数。

④ 运动语言

人物 12fps（一拍二）、环境 24fps；每个缓动函数写名字；「先静后动，决定性一笔 4 帧内划完」。动画的灵魂在节奏，节奏必须写成数字。

⑤ 镜头语言

一张 beat→运镜对照表：开场固定机位 → 横移长卷 → 低角度威胁 → 极近特写 → 结尾拉远全卷。直接当分镜表用。

⑥ 声音设计

指定乐器（古琴 F 宫五声调式）、规定「静音窗口里只允许一滴水和一声剑鸣」、foley 材质对应（墨滴=坠落+湿闷响）。声音不是事后配的，是和画面一起写的。

⑦ 字幕规范

字幕=题跋：什么字体、放画面哪个空白处、湿着出现 0.35s 后干透。连字幕的位置美学都有规矩。

⑧ 踩坑清单

「干笔别用虚线模拟」「字幕要重置坐标系否则会滑出画面」——每坑一句对策。这是迭代多轮后攒下的血泪，也是最值钱的部分。

⑨ 生产配方

文件结构（引擎/角色/场景/时间线各一个 js）+ 从渲染到混流的完整命令链。让 AI 知道「工程长什么样」，它才不会把所有代码糊在一个文件里。

04 / WRITE YOUR OWN

下次自己写：九段式填空模板

把上面九段压缩成一个可填空模板。绿色部分替换成你的内容，其余照抄结构。即使不写给 AI 执行，填一遍也能帮你把模糊的想法想清楚。

# 风格 Prompt 填空模板（复制后替换 <...> 内容）

<作品类型>：一支 30–60 秒的 <风格名> 风格短片，主题是 <用户给的主题>。
<风格定义>：视觉锚 = <像什么媒介/哪部作品的气质>；只借语法，不抄具体画面。
<天生神力>：这个媒介独有的 3–5 个表现手法（如：留白、一笔成形、转场即翻页），本条至少用 <N> 个，最强的放在情感峰值。
<视觉规范>：主色 <#色值>、强调色 <#色值>；字体 <字体名>；材质规则 <笔触/质感规则>；分辨率 <1920×1080>、帧率 <24/60>fps。
<运动规则>：<哪些元素> 用 <12/24/60>fps；缓动用 <ease 名称>；<哪个动作> 必须卡音乐节拍。
<分镜表>：开场 <固定/横移> → 发展 <运镜> → 高潮 <运镜> → 结尾 <拉远/定格>。
<声音设计>：配乐 <乐器/曲风>；<哪一秒> 必须静音；音效材质对应 <动作→声音>；旁白 <音色/语速>，念完用 whisper 校对。
<字幕规范>：位置 <画面中哪块空白>、字体字号、出现/消失方式、停留时长 ≥ <1.8>s。
<已知坑>：<你预期会出什么问题 → 对策>（做完一轮就回来补一条）。
<工程要求>：分文件结构 <引擎/场景/时间线>；所有随机效果带 seed；渲染 → 混音 → 合成一条命令链跑通。
✗ 反面教材（AI 只能瞎猜）

「帮我做一个水墨风格的动画，讲坚持的重要性，要高级、要有电影感。」

→ 没有参照系、没有色板、没有镜头、没有节奏。AI 只能给你「看起来像 PPT 的墨水飞来飞去」。

✓ 照着模板写（AI 能直接开工）

「45 秒水墨短片：宣纸 #F2ECDE 底、墨分五色，唯一红色是结尾印章。讲一个跑者： blank 纸起跑 → 一笔画出山路 → 飞白表现力竭 → 静音 2 秒后一笔登顶 → 拉远 reveal 整条卷轴盖章。人物 12fps 环境 24fps，古琴配乐，旁白英音男声语速 0.85，字幕作题跋放左上留白处。」

→ 每个词都能被执行、被检查。
