# 收录新案例 · 入库指南

这个网站是**数据驱动**的：所有案例都写在 `data/cases.json` 里，页面只是它的渲染器。
所以「别的 Agent 生成的案例合并进来」= 往 `data/cases.json` 加一条记录 + 放一张封面图。

## 最快方式（推荐）

把案例发给 Kimi（这个对话），说一句「收录进案例墙」即可。给我以下任意组合：

- 一个链接（在线 demo / GitHub 仓库 / X 帖子）
- 一个 HTML 文件或 zip 包
- 一句话描述 + 你用的 Prompt

我会自动补齐其余字段、截图做封面、写入 cases.json、重新发布版本。

## 案例记录格式（cases.json 每条字段）

```json
{
  "id": "qingming-bianjing",            // 唯一英文短横线 id
  "name": "清明上河图 3D 汴京城",        // 卡片标题
  "author": "SilentFleetKK",            // 原作者（必须标注）
  "author_url": "https://github.com/SilentFleetKK",
  "collection": "d3",                   // 合集标签：d3 / lemo-opuscar / yihui / mine（自己做的）
  "category": "3d",                     // motion / interactive / explainer / 3d / film-style / game
  "tech": ["threejs", "playable"],      // 技术标签，筛选用
  "poster": "assets/posters/xxx.webp",  // 封面图路径（960×540 或 16:9）
  "prompt": "……完整 Prompt 全文……",
  "prompt_status": "original",          // original 原文完整 / partial 部分公开 / reverse 逆向整理 / none 未公开
  "note": "批注：这个案例值得学的点（没有就留空字符串）",
  "links": [
    {"label": "▶ 在线试玩", "url": "https://…"},
    {"label": "GitHub 源码", "url": "https://…"},
    {"label": "X 原帖", "url": "https://…"}
  ],
  "added": "2026-10-05"
}
```

## 字段规矩（诚实三原则）

1. **作者必标**：`author` + `author_url` 必填；自己做的就写自己的名字
2. **Prompt 不编造**：原作者给了原文 → `original`；只公开了部分 → `partial`；你自己或 Agent 逆向整理的 → `reverse`；没有 → `none`（卡片会显示「未公开」，不留空骗人）
3. **封面要真实**：必须是案例真实运行的截图或作者公开图，不用示意图冒充

## 自己动手（不用等我）

1. 封面图放进 `assets/posters/`（16:9，jpg/webp 均可）
2. 打开 `data/cases.json`，照上面格式在数组里加一条（`,` 别漏）
3. 刷新页面，新案例自动出现在墙上，筛选和搜索自动生效

批量入库：把多个案例写成同一个 JSON 数组发我，我一次性合并。
