# AI Immigrant — 迁徙图鉴（The Atlas）

黑白铜版刻蚀风格的 WebGL 涡旋画廊：AI Immigrant 频道的视觉官网。35 张版画分属九个章节（Overture / Origins / Charts / Crossing / Body / Industry / The Door / Mind / Machine Age / The Mirror），滚轮与触屏驱动缓慢漂移，点击查看图注详情，支持键盘 ←/→ 翻页。

## 技术栈
React + TypeScript + Vite + Three.js（WebGL instanced vortex）+ Lenis + GSAP
