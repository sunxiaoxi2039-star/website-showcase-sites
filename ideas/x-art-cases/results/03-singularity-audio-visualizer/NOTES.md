## fixed 改了什么、为什么
全部改动都在 `fixed/index.html`，只调数值和修小 bug，结构和音乐没动。

1. **亮度与辉光（主因）**
   - 吸积盘 HDR 亮度大幅下调：温度项 `(1+4t)` 改成 `(.08+.7t)`，多普勒增亮上限从 5 降到 2.1。
   - 盘面粒子的颜色和透明度约降到原来的 1/3，喷流粒子亮度从 2.6 降到 1.1。
   - UnrealBloom 的阈值从 .55 提到 .9，强度约减半，半径从 .55 缩到约 .25。
   - 原因：UnrealBloom 的高通把超亮像素整块送进模糊链，大面积 HDR 会糊满整屏。
2. **阴影保持纯黑**
   - 被视界吞掉的光线，光子环的辉光乘 .03，光子环也收窄。
   - 星云亮度减半。
   - 曝光从 1.0 降到 0.9。
3. **色差和闪白减半**：`uCA` 的偏移系数由 .012 改为 .005，闪白系数由 .55 改为 .35，避免 drop 段画面边缘严重彩边。
4. **GLSL `pow(负数, 2.)`**
   - 星云带和冲击波环两处的 `pow` 底数可能为负，这在规范上是未定义行为，有的 GPU 会出 NaN。
   - 已改成 `x*x`。
5. **包络按真实时间衰减**
   - 之前闪白、踢鼓包络用的是限幅到 0.1 s 的帧间隔。掉帧或切后台回来时，闪白会挂着不退。
   - 现在包络和镜头缓动改用真实时间（上限 2 s）衰减，相位累加仍用限幅后的 dt。
6. **自适应画质下限**
   - 原来在低端设备上，画质可能一路降到 0.4 倍像素，画面糊、辉光相对变大。
   - 现在像素比最低保持 0.75。
7. 加了 `<link rel="icon" href="data:,">`，消掉 favicon 404，控制台 0 错误。
8. 加了 `?debug` 时才暴露的 `window.__sgDbg`，只用来自检，正常访问不受影响。

## 技术要点
- **音频（全 WebAudio 现场合成，无采样）**
  - 前瞻调度器：25 ms 轮询，前瞻 0.15 s，后台时 1.6 s。
  - 编配：9 段，从 intro 一路到 outro，有两次 build 加 drop、一段 break、一段 switch、一段 final。
  - 乐器：kick、snare、clap、hat、crash、impact、riser、dive、pad、pluck、supersaw、wobble（用 `setValueCurveAtTime` 写 LFO 滤波曲线，可叠 growl 峰值滤波）、reese。
  - 母线：sidechain 压限，程序生成冲激响应的卷积混响，附点八分延迟。
  - 链路：压缩器 → tanh 限幅 → 分析器（FFT 2048）。
  - 跳段时换一组新母线，把已排程的音符静音。
- **音画同步**
  - 每个鼓点在排程时就把带音频时钟时间戳的事件推进 `visQ`，渲染帧按 `ctx.currentTime` 取出。
  - wobble 段落记进 `wobSegs`，画面按同一条 LFO 公式复算，吸积盘和视界跟着 wobble 精确起伏。
- **黑洞**
  - 全屏四边形做光线步进，走光子测地线 `a = -1.5·h²·r̂/r⁴`。
  - 穿过赤道面时采样薄吸积盘。
  - 盘面：开普勒剪切，用两层流噪声交叉淡化防止卷绕过度。
  - 相对论多普勒增亮，r=1.5 处的光子环，踢鼓冲击波环。
  - 程序星空和星云。
- **其余三维元素**
  - GPU 粒子，桌面 2.4 万、手机 9 千：盘面粒子螺旋吸入，另有 ±y 双极喷流，被阴影挡住的粒子隐藏。
  - FFT 频谱冠：144 根，对数映射、镜像。
  - 示波器光环：跟着相机做 billboard。
- **后期**：UnrealBloom → 自写镜头 pass（色差、闪白、颗粒、暗角）→ OutputPass（ACES 加 sRGB）。
- **镜头导演**
  - 每段一套 LOOK（距离、仰角、转速、盘亮、喷流、配色、辉光、漂移），画面缓动过渡。
  - build 段推镜加速，drop 段震屏和滚转，gap 段压暗盘面、加重引力。
- **交互**
  - 点按钮才出声，满足自动播放限制。
  - 拖动环绕，滚轮或双指缩放。
  - 快捷键：空格暂停，H 隐藏 UI，F 全屏。
  - 进度条可点击跳段，并标出各段起点。
- **性能**：devicePixelRatio 上限 2，按帧时自适应画质，手机减少步进次数和粒子数，遵守 prefers-reduced-motion。

**毛病清单**
- 入口页：大标题压在黑洞正中，桌面和手机都挡住主体；字体是系统 Helvetica，很普通。
- 画面：星云偏亮再叠上辉光，黑底发灰；drop 段整体过曝，色差彩边很重。
- 元素：盘面粒子太大太亮，像撒彩纸；喷流是一串胖粒子；频谱冠 1 像素细线离镜头太近，像划痕；示波器环是一根 1 像素细线浮在盘面前。
- 控制台：0 错误。性能风险：每像素 110 步光线步进，加上 2.4 万粒子，软件渲染很慢；事件队列每帧 `splice`（影响很小）。
- 手机：竖屏能用，但辉光半径按像素算，低分辨率下相对变大，drop2 段一片灰雾。
- 减少动态：有 `mk` 系数衰减震屏和滚转，基本合格；色差和闪白仍偏重。

**评分**：5.5 / 10。能跑能听，结构也好，但画面脏、灰、过曝，撑不起"奇点"这个题目。

**升级计划**
1. 入口页重新构图：黑洞抬到标题上方，开场后再滑回画面中心；换 Jost 加 JetBrains Mono 做字体排版。
2. 调色链改成 HDR → AgX 色调映射 → 分离色调 → sRGB → 抖动，高光按色相滚降，不再平切发白；每段 LOOK 加曝光参数。
3. 星云压成深色低亮，黑底保持纯黑，去掉灰雾；辉光强度和半径按屏幕尺寸缩放，手机不糊。
4. 喷流改成解析式高斯光束：亮芯加外鞘，抛物线准直，外鞘缠螺旋丝，亮芯带行进的亮结，随高度衰减，并且和吸积盘一起被引力透镜弯折。
5. 频谱冠改成柔光带：用实例化的面片代替 1 像素线；左右镜像对称，跟着相机转，低频立在黑洞后面像一顶冠，近处的弧段在到镜头前就溶解掉。
6. 示波器环贴到光子环上，改成柔光带：波形向阴影里凹进去时才看得见；下半弧在盘的近侧后面，压暗处理。
7. 粒子缩小变淡，喷流火花变细，色差和闪白按段落分级，减少动态模式下进一步压低。

## 精修
所有改动都只在 `final/index.html` 里做，这个文件从 `fixed/` 复制而来；`oneshot/` 和 `fixed/` 一个字都没动，修改时间仍是 09-26 11:30 和 11:44。音乐和排程代码没动，和 fixed 逐行比对，只差一个空行。下面按复评里的升级计划逐条对照。

1. **入口页构图与字体**
   - 改投影矩阵的偏移（`elements[9]`），把黑洞抬到大标题上方。按下开始键后，`gateK` 缓动归零，黑洞滑回画面中心。
   - 从 jsDelivr 的 @fontsource 包加载 Jost 和 JetBrains Mono，系统字体只作后备。
     - 标题用细体、大字距，带暖色渐变。
     - 说明文字、快捷键提示和两个顶角的信息栏用等宽小字。
   - 播放界面也统一成这套字体：左下角是段落名，进度条上标出各段起点。
2. **调色链**
   - 渲染器关掉自带的色调映射，改由自写的 grade pass 一次做完：色差 → 闪白 → 暗角 → AgX（punchy 风格）→ 分离色调 → sRGB → 抖动。
   - 高光按色相滚降，drop 段不再平切成白。
   - 每段 LOOK 多了一个 `expo`（曝光）参数，break 段偏亮，final 段偏暗。
3. **黑底与辉光**
   - 星云压成深色低亮。
   - 辉光的强度和半径乘上 `bloomK = clamp(√(宽×高)/1100, .45, 1)`，手机上的辉光不再糊成一片。
   - 这一轮又把阈值从 .9 提到 1.0，半径从 `.3+.15·energy` 收到 `(.1+.12·energy)·bloomK²`。
   - 阴影内像素从原来的 85–190（灰）降到约 40–130；较亮的读数出现在踢鼓瞬间。
4. **喷流**
   - 不再用一串胖粒子，改成解析式高斯光束：光线步进的每一小段里，求光线到自转轴的最近距离，再对高斯剖面做线积分。
   - 结构：
     - 亮芯是蓝白色，上面有向外跑的亮结；
     - 外鞘缠着螺旋丝，写成 `cos(2φ − twist)`，不用 `atan`，所以轴上不会出 NaN；
     - 按抛物线准直，越高越宽，并由蓝转紫。
   - 喷流和吸积盘一起在测地线步进里计算，所以同样被引力透镜弯折。踢鼓时亮度最多约翻一倍。
5. **频谱冠**
   - 做成 160 根实例化的柔光带：FFT 按对数分成 80 个频带，左右镜像，低频在黑洞正后方。
   - 每根都朝向相机，最窄 1.5 像素，近处的弧段在到镜头前就溶解掉。
   - 被阴影挡住的判断从逐顶点改成逐像素：按像素的冲击参数判断它是否在视界之后。以前逐顶点插值时，冠条会从阴影里隐约透出来，现在不会了。
6. **示波器环**
   - 贴在光子环上，做成柔光带，只在波形向阴影里凹进去时才看得见。
   - 下半弧按 `smoothstep(-.5, .08, sin θ)` 淡出，不再浮在近侧盘面前面。
7. **光子环（本轮新发现并修掉）**
   - 原来的光子环辉光在步进循环里阶梯式累加，会在阴影边缘画出一圈珠子，压在近侧盘面上。
   - 现在改成解析环：
     - 用光线的冲击参数 b 和临界值 `2.598·rs`（即 3√3/2）之差算环的亮度；
     - 用光线进入 2.4 倍视界半径时的透射率加权，被近侧盘面挡住的地方自动变暗。
   - 环细而连续，随踢鼓和低频脉动。
8. **粒子、色差与减少动态**
   - 盘面粒子缩小变淡，喷流火花变细。
   - 色差按段落分级：只有 drop 类段落的踢鼓才给大幅色差，其余段落的色差约是它的 1/5。
   - 减少动态模式下：
     - 震屏、滚转等随拍冲击统一乘 `mk = 0.35`；
     - 色差固定为很小的常数，闪白只剩约 1/7；
     - 系统设置一改，页面实时响应。
9. **稳健性**
   - three.js 加载失败的提示，等待时间从 9 秒放宽到 15 秒；模块一加载完就清掉这条提示。原来在慢网或机器高负载下，页面其实已经在跑，红字仍会误报。
   - 着色器里给开方、对数和除法加了下限保护，喷流不用 `atan`，避免个别 GPU 上出 NaN 黑点。
