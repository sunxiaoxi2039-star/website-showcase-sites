## fixed 里改了什么、为什么（共 3 处，都带中文注释）
1. **方块上的词变成条纹（文字不可读）**
   - 现象：块面着色器用浮点 `mod(vWord,5.)` 和 `floor(vWord/5.)` 算图集行列。浮点误差会让第 5/10/15/20 号词取到图集格子外，所以「即レス」「前倒し」「速く」「報告」这些词在 3–14 秒显示成横向条纹。
   - 修法：先把词号四舍五入成整数，再用整数算行和列。
   - 验证：fixed-t13-hi 里所有词块（这一帧约 70 块）文字全部清晰。
2. **手机上舞台溢出、整页被裁切**
   - 现象：CSS 初始值 `--u:5px` 让舞台宽 500px，JS 还没来得及缩放时，手机的布局视口已经被撑宽，整页被缩小后左右裁掉。oneshot-phone-t25 实测舞台 left -31.5，宽 438，而视口宽只有 407。
   - 修法：`--u` 的初始值改成 `min(1vw,.5625vh)`，舞台改为 `position:fixed` 加四边 0 和 `margin:auto` 居中。
   - 验证：fixed-phone 实测 375×812 视口里舞台 [0, 72.7, 375, 666.7]，上下留黑边，不再溢出。
3. **窗子“完全封死”时地面仍漏红光**
   - 现象：拱边碎角和拱外那些没有方块的格子，遮罩值恒为 1（全开）。地面投影和光柱按遮罩插值，于是 11–14 秒本该全黑时仍有一圈红光漏到地上。
   - 修法：这些格子改为跟随离它最近那块方块的开合。没有新增方块，随机数序列和编舞完全不变。
   - 验证：fixed-t13-hi 画面全黑，只剩文字；fixed-t25、fixed-t31.8 里连锁坠落和俯视地面的圣母、天使都照常。

## 已知问题（没再修）
- 彩窗经过 bloom 和 ACES 后偏粉彩、偏霓虹。边框上的宝石像一圈灯泡，不像原作那种深色玻璃。
- 天使下半身的云朵被 bloom 冲成白色。圣母脸在地面投影的尺度下看不出五官。
- 俯视地面完整清楚的时间只有约 31.5–33.5 秒，之后就进入白场。
- 用无头 Chrome 的软件 WebGL 截图很慢。oneshot 阶段在 540×960 的 t25/t33 截图里出现过“顶部约 145px 在底部重复一遍、按钮消失”的现象（HTML 文字也跟着重复），判断是无头合成器的伪影。fixed 重拍的 t25 没再出现。
- 真机性能没测。体积光是半分辨率 40 步光线步进，低端手机可能掉帧，但时间轴按固定 1/30 秒推进，不会乱序。
- `evidence/build-poster.png`（21:19）不是这两个 agent 生成的，来源不明，留着没动。

## 用到的技术
- three.js 0.169.0，用 importmap 从 cdn.jsdelivr.net 加载并锁版本；用到 RoundedBoxGeometry、InstancedMesh（全部词块一次绘制）、ShaderMaterial、Data3DTexture。
- 彩窗全程序化绘制：Canvas2D 加 Path2D 画 1024×1536 的对称构图，有圣母、曼多拉光轮、两位展翼天使、玫瑰窗和红宝石边框。**同一张贴图同时用在**窗面、地面投影、体积光柱和尘粒着色上，满足 prompt 要求的“窗、地、光同一图”。
- 方块遮罩：7×11 的 DataTexture。`winOf(p)=vec2(p.x, p.y+p.z-ZG-WY0)` 实现 45° 阳光投影，窗上哪块掉了，地上和光柱就精确地亮哪一块。
- 自写 HDR 后期链：半分辨率体积光光线步进（40 步），bloom 逐级降采样再升采样，ACES 调色，最后加白场 veil 和暗角。
- 固定 1/30 秒一帧，每帧画面只由帧号决定。`?t=秒` 可以跳到任意时刻，`window.yohaku.{seek,play,pause,frame,t}` 方便截图和复查。
- 文字只用系统明朝体（Hiragino Mincho / Yu Mincho / Noto Serif JP 回退）。最后一句「豊かさは余白に宿る」竖排。
- 声音用 WebAudio 程序化合成，只有点了「音をつけて最初から」按钮才出声。devicePixelRatio 上限为 2。
- 零花费：没调用任何付费或生成类 API，全部是代码。

### 发现的问题

- **减少动态**：不支持 `prefers-reduced-motion`，critique-reduced 里照常播放全片。
- **桌面画幅**：1440×900 下两侧是大片黑边，画面只占中间约三分之一。「音をつけて最初から」按钮常驻，压在画面下部。
- **交互**：只有键盘（空格、方向键、R），没有进度条。手机上无法暂停或跳转（critique-interact）。
- **性能**：
  - 每帧都在 new 向量和矩阵，GC 压力大。
  - 没有自适应画质；页面切到后台仍在渲染。
  - 手机上体积光固定 40 步，偏重。

### 评分

改动前 art_score_before = **6**。

- 编舞和“窗、地、光同源”的技术骨架都扎实，时间轴完全按 prompt 走。
- 但 prompt 最看重的结尾没有做到：地面上读出圣母与天使、宝石般的色彩。

### 升级计划

1. **重画彩窗**：宝石调色板、玻璃斑驳质感，给圣母与天使画灰绘五官，翅膀改成向上展开的分带羽翼。
2. **调色**：改用保持色相的色调映射加分离色调，压低 bloom，让玻璃像宝石而不是霓虹。
3. **镜头**：重排关键帧，把俯视地面圣像的停留拉长到约 3 秒，下降和转身更平顺。
4. **展厅式页面**：全视口画布，画面外做环境溢光；宽屏放题签和章节表；可拖动进度条、章节跳转、闲置时隐藏界面。
5. **其他**：减少动态静帧模式、预分配、自适应画质、页面隐藏时暂停、补 favicon。
