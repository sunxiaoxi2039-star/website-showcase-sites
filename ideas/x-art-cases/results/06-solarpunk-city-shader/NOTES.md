## 一次成功吗
部分成功。oneshot 在桌面 1440×900 和手机 375×812 下控制台都是 0 报错，也不黑屏，城市、道路、塔楼、树和花瓣都能看到。

但它有一个 SDF 边界 bug，画面上看得很明显。每栋楼屋顶上方都多出一根半径 2.7、一直通到天上的“幽灵圆柱”，材质算成了植物。结果画面上半部分铺满发白的绿墙，天空几乎看不到，达不到“visually interesting”。所以复制到 fixed/ 修正。

## fixed 改了什么，为什么
1. **修掉屋顶幽灵柱（主要 bug）**
   - 原因：屋顶细节区的进入条件是 `rad < 2.7`，外面的兜底距离是 `max(rad-2.7, H-0.3-y)`。在屋顶上方、`rad` 稍大于 2.7 的地方，兜底距离会趋近 0，光线就把它当成表面命中了。
   - 改法：进入条件放宽到 `rad < 3.2 && y > H-1.3`，兜底改为 `max(rad-2.7, H-1.0-y)`。这样兜底距离恒大于等于 0.3，永远不会被命中，同时仍是屋顶物体的合法下界。
2. **提高自适应分辨率的下限**：从约 3 万像素提到约 8 万，首帧从 11 万提到 12 万。慢设备上宁可帧率低一点，也不让画面糊成马赛克。
3. **远处去掉花点**：植物上的随机粉/黄花点只在 35 米以内出现，避免远处闪成噪点。
4. **飘落花瓣贴脸淡出**：从 0.6–2.2 米开始渐显，避免镜头前出现大块模糊色斑。
5. **光线和雾（贴合“visually interesting”）**
   - 原来太阳在镜头背后，画面是平的；改成从右侧略偏后照过来，塔楼有明暗转折。
   - 太阳能“叶片”的朝向跟着新太阳方向调整。
   - 地平线色从米白改成带点蓝的灰，天顶更蓝，雾密度从 0.0095 降到 0.0065，天空和远景的层次更清楚。
6. **风线加强**：亮度系数从 `0.12+0.28g` 提到 `0.18+0.5g`，让“看得见的风”在亮背景上也看得出来。

fixed 版控制台在桌面和手机下都是 0 报错。

## 已知问题
- **截图偏糊，是测试环境造成的，不是画风**
  - 自检用的无头 Chrome 走 SwiftShader 软件渲染，这个 shader 每帧要 1 秒左右。
  - 自适应分辨率会降到约 358×224（桌面）/ 192×416（手机）再平滑放大，所以截图看起来颗粒粗。
  - 真实 GPU 上帧时间低于 24ms 会自动升分辨率（上限 DPR 2），画面会清晰得多。
  - CSS 用默认平滑缩放，没有用 pixelated。
- 街树的树冠在少数高塔旁边会和二层阳台轻微穿插。
- 太阳能叶片从下往上看是背面（浅灰）。
- 从某些角度看，远景塔楼的立面花纹会有轻微闪烁。
- 在 twigl 里 `mouse` 初始是 (0,0)，shader 把它当作屏幕中心处理，所以不动鼠标时视角是正前方。

## 用到的技术
- **单个 fragment shader**：只用 `resolution` / `mouse` / `time` 三个 uniform，写法兼容 twigl classic 模式（GLSL ES 1.0、`gl_FragColor`）。页面上有“复制 twigl 代码”按钮，贴进 twigl 就能跑。
- **无限城市**
  - 12 米网格做域重复，路在格子边界上，塔楼在格子中心。
  - 每步只算本格物体，再用“到本格边界的射线距离”限制步长（cellBound），不会穿进邻格。
  - 用 hash 决定楼高、半径、二段收分、配色，约 10% 的格子是口袋公园。
- **塔楼**
  - 圆角圆柱加随高度收分和起伏。
  - 每层有阳台板和绿篱花槽；16 个扇区挂垂藤，随阵风摆动。
  - 屋顶随机三种：顺风转的风力机、倾斜的太阳能叶片加小树、屋顶花园。
- **道路**：柏油路面加中线虚线、绿色自行车道、边线、人行横道、路口环线；路缘、草带、广场铺砖带苔藓缝。
- **风（一直在吹）**
  - 统一的阵风场 `gust(xz)` 沿风向传播。
  - 它同时驱动：树冠摇摆和叶面起伏、垂藤摆动、绿篱抖动、草地上成片移动的“风痕”光泽、野花点头、风机转速。
  - 顺风飘的花瓣、叶片和种子：3D DDA 网格，按像素尺寸抗锯齿。
  - 三层相机相对的波浪风线。
  - 云也顺风漂移。
- **光照**：太阳软阴影（32 步），天光，地面反弹光，4 次采样 AO，高光，玻璃和太阳能板反射天空，叶片逆光透射；然后是指数雾、ACES 色调映射、gamma、暗角。
- **页面**
  - WebGL1，全屏三角形，DPR 上限 2，按帧时间自适应渲染分辨率，resize 和绘制在同一帧完成。
  - 处理了 context lost / restored，编译错误会显示在页面上并输出到 console.error。
  - 鼠标或触摸拖动可以环顾，松手后缓慢回正；`prefers-reduced-motion` 时动画减速一半。
- **声音**：点“开启风声”后才建 AudioContext，不会自动播放。
  - 粉噪声经带通模拟风声，高通模拟树叶沙沙声。
  - 音量和音色跟着镜头位置的阵风强度变化，声相缓慢漂移。
  - 切到后台时暂停。
- **零成本**：全部程序化生成，没有外部库、贴图、模型或付费 API。

### 问题

- **bug**
  - 切回前台后第一帧的 dt 很大，会被当成慢帧，分辨率被乘以 0.7。
- **动效**
  - reduced motion 只是把速度减半，镜头仍在前进。
  - 没有暂停或定格，截图和海报只能拿到自适应后的低分辨率帧。
- **美术**
  - 太阳位置读不出来，也没有长影子。
  - 叶色单一、偏塑料。
  - 灰色的太阳能叶片底面像飞碟，最抢眼。
  - 玻璃立面有灰斑块。
  - 构图正中对称，近处大楼糊成一片。
- **性能**
  - 一次 draw call，每帧不分配内存，DPR 上限 2。
  - 160 步行进、32 步阴影、4 次 AO、4 次法线，负担偏重，靠自适应分辨率兜底。
  - headless 软件渲染只有 358×224，所以截图是块状的。
- **手机**：布局可用，按钮不挤。
- **界面**：排版普通。

### 评分

6 / 10。技术完成度高，但画面观感停在“灰天里的一座绿城”，风在静帧里不成立。

### 升级计划

1. **金色斜阳**：太阳降到 24° 高，偏右 65°。暖主光配冷天光和暖地面反弹光，让长影子横过街道。
2. **天空与大气**：地平线朝阳方向暖、背阳方向冷。雾贴地浓、高处淡，太阳方向有内散射。云变暖并顺风漂移。
3. **调色**：每个街区的叶色略有不同。立面用奶油、赤陶、鼠尾草绿，玻璃压暗，少量窗户亮暖灯。行道树开粉花和金花。
4. **太阳能花**：换掉灰色“飞碟”，改成三瓣靛蓝光伏花瓣，随阵风抖动。
5. **让风读得出来**：风线改成彗尾状的气流丝，逆光更亮。花瓣加大并有阳光闪烁，树的摆幅加大。
6. **镜头**：焦距加长，加偏航和轻微侧倾，打破正中对称。reduced motion 下镜头几乎静止，但风照吹。
7. **后期**：光晕、曝光和 ACES 之后，再做饱和度、冷暗部暖高光的分离调色、S 曲线、暗角和抖动去色带。
8. **界面与交互**
   - 重新排版的说明卡。
   - 「定格」按钮和空格键：定格后逐条补渲到全分辨率，顶部有进度条。
   - 方向键环顾。
   - URL 参数 t / still / ss / ui。
   - 修掉切后台的 dt bug。

## 精修

final/index.html 从 fixed/ 复制后只在 final/ 里改。oneshot/ 和 fixed/ 一字未动。

### 改了什么

- **修 bug**
  - visibilitychange 回到前台时设 skipDt，第一帧按 16ms 算，不再误降分辨率。
  - reduced motion 下页面在 shader 前加 `#define REDUCED`：镜头时间变成 40 + time×0.12，几乎不动，风、树和花瓣照常。复制给 twigl 的代码不含这一行。
  - 风声的阵风采样同步改用镜头时间。
- **光**
  - SUN 改为 (0.8278, 0.4067, 0.3861)。
  - 主光 SUNC×2.3，天光 SKYC×0.85。
  - 暖色地面反弹光分两路：一路侧向，一路朝下，照亮阳台底面和太阳能花底面。
  - 叶片逆光透射受阴影调制。
  - 阴影 32 步，最大步长 2.8。
- **大气**
  - 新 skyBase：冷暖地平线、天顶蓝、太阳光晕。
  - 高度雾：密度随高度指数衰减，80 米外加速收雾，雾色取同方向地平线色。
  - 太阳方向内散射。
  - 暖色云顺风漂。
- **材质**
  - 叶子改用三维值噪声，不再出现西瓜纹，并加了叶簇法线扰动，绿篱和树冠不再像塑料。
  - 每个街区的色相略有不同，阵风经过时叶面翻出银绿。
  - 行道树开粉花或金花，树冠里的小花点是圆的。
  - 立面：四种墙色，玻璃窄一些、更深，约 10% 的窗户亮暖灯（上亮下暗）。
  - 立体绿墙有常春藤纹理和法线扰动，垂藤更细、边缘带叶状起伏。
- **太阳能花**：三瓣椭圆花瓣向上张开，随阵风抖动。顶面是靛蓝电池片加暖金栅线，底面奶油色。
- **风**
  - 三层气流丝改成彗尾形状，核心加光晕，强度随阵风变化，逆光时加亮，按像素宽度淡出。
  - 花瓣加大、有闪烁，近处 1.4 米内不画，避免糊在镜头上。
  - 树摆幅约为原来的 2 倍。
- **镜头**
  - 焦距 1.7（竖屏 1.25）。
  - 偏航由两个正弦叠加，俯仰随高度补偿，带轻微侧倾。
- **后期**
  - 光晕，曝光 0.92，ACES。
  - 之后饱和度 1.1，冷暗部暖高光，25% 的 S 曲线。
  - 暗角和 1/255 抖动。
- **页面**
  - 新说明卡：金色小标题、中英双标题、提示语。
  - 按钮：开启风声、定格/继续、复制 twigl 代码（手机上显示短标签）。
  - 定格后按条带渐进补渲：用 copyTexImage2D 把当前帧拉伸成占位，条带高度随帧时间自适应，上限约 620 万像素且单边不超过 4096，顶部有金色进度条。补完后 rAF 停下，不再耗电。
  - 键盘：空格定格，方向键环顾，Esc 或 0 回正。
  - URL 参数：?t=、?still=1、?ss=1~2、?mx=&my=、?ui=0。
  - 着色器用 KHR_parallel_shader_compile 异步编译，编译期间页面不卡。
  - window.__solarpunk 可读取帧统计。
