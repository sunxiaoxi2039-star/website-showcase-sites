# 栖居 Habitat · 松间一隅

开放屋顶的交互式 3D 家居空间。六个房间可独立探索，32 组家具与陈设附设计、材质和尺寸讲解。

- 真实材质、白模、线框三种显示模式。
- 家具显隐、空间标注、昼夜切换与自动室内照明。
- 房间漫游：拖动环顾，WASD 或方向键移动，手机支持屏幕方向按钮。
- 一键正交平面图，默认线框，支持缩放、平移与点选。
- 技术：Three.js / 原创程序化模型及纹理 / Vite。
